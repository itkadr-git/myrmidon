title: Расхождения в знаниях

---

Модуль знаний может вести журнал расхождений, когда документированная информация перестаёт соответствовать проверенной реальности. Запись содержит затронутую страницу, прежнее и текущее состояние, способ проверки и необязательную ссылку на задачу. Журнал отделён от редакций элементов знаний: он фиксирует расхождение и последующую работу, а не заменяет опубликованный материал.

## Жизненный цикл

Новая запись получает статус `open`. По умолчанию списки содержат только открытые записи; разрешённые записи можно включить отдельным параметром. Подсчёт учитывает только открытые записи выбранного гнезда. Разрешение записи меняет статус на `resolved` и обновляет временную метку. Для ежедневного оповещения также можно найти открытые записи без ссылки на задачу, созданные более 24 часов назад. Этот запрос сам по себе не назначает исполнителя и не создаёт задачу.

Модель данных хранит идентификаторы компании и гнезда, страницу, прежнее и текущее описания (`was` и `became`), сведения о проверке, необязательную ссылку на задачу, статус, идентификаторы акторов и временные метки. При выдаче списка и поиске просроченных неназначенных записей результат сортируется по времени создания.

## API и границы

Используются следующие маршруты в контексте компании:

- `POST /api/myrmidon/companies/:companyId/knowledge/deviations` — записать расхождение.
- `GET /api/myrmidon/companies/:companyId/knowledge/deviations` — получить список; параметры `includeResolved` и `limit` управляют результатом.
- `GET /api/myrmidon/companies/:companyId/knowledge/deviations/count` — подсчитать открытые записи.
- `POST /api/myrmidon/companies/:companyId/knowledge/deviations/:id/resolve` — разрешить запись.

Маршрут привязывает гнездо через сервис знаний, ограниченный выбранной компанией. Нельзя передавать произвольный идентификатор гнезда для обхода границы компании. Если лимит не указан, список ограничен 100 записями. Запрос просроченных неназначенных записей доступен сервисному слою, но не является тем же самым, что публичный маршрут списка.
