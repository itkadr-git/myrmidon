Модуль знаний — это управляемое хранилище корпоративных знаний. Он дополняет доступную для поиска память Hindsight и регламенты wiki с ограничением по ролям: элементы знаний — долговечные записи с явным состоянием публикации, которые можно проверять и пересматривать.

## Модель

Один элемент может иметь тип `note`, `wiki`, `answer`, `task_outcome` или `rule`. У каждого элемента есть добавляемые ревизии, источники, предложения, события и извлечённые ссылки `[[slug]]`. Элементы ограничены компанией и nest; текущая схема использует один nest на компанию. Полнотекстовый поиск реализуется через порт, а на границе подключения используется поиск PostgreSQL.

Состояние элемента проходит явную машину состояний: draft, in review, published, archived или superseded. Состояние ревизии — draft, submitted, approved или rejected. Черновик никогда не меняет `deliveredRevisionId`; публикация явно перемещает этот указатель. Откат создаёт дополнительную ревизию, скопированную из целевой, поэтому журнал аудита остаётся добавляемым.

Правила строже обычных заметок: для них обязательно одобрение и указание `approver_kind`. Одобрение без этого типа или актором неподходящего типа отклоняется, а не обрабатывается по разрешительному умолчанию.

## Журнал ревизий и источники

Ревизии сохраняют неизменяемый аудиторский след всех изменений элемента знаний:
- **Заметки об изменении (`note` / `changeSummary`):** Каждая ревизия фиксирует краткое описание сделанных изменений. Агенты передают его через параметр `changeSummary` при создании или обновлении ревизий через инструмент MCP `knowledge_write_draft`.
- **Структурированные источники (`sources`):** Ревизии могут содержать ссылки на подтверждающие артефакты, обосновывающие правку. Каждая ссылка включает:
  - `kind`: категория источника (`task`, `pr`, `issue`, `run`, `document`, `decision` или `url`).
  - `ref`: идентификатор, относительный путь или внешний URL (например, ключ задачи `OPE-10487`, номер/ссылка на PR `#2187`, slug документа wiki или id прогона).
  - `note`: опциональный комментарий, поясняющий назначение ссылки.
- **Отображение в интерфейсе:** Панель ревизий (`RevisionsPanel` в `Ui2Knowledge`) отображает журнал ревизий с автором, временем, примечанием об изменении (`.ui2-knowledge-revision-note`) и ссылками на источники (`.ui2-knowledge-revision-sources`) для быстрого перехода к задачам, PR, прогонам, документам wiki или внешним страницам.

## Контракт KNOWLEDGE_INDEX

Канонический экспорт дерева — формат обмена для индекса знаний. В нём фиксированный порядок ключей и содержимое с префиксом длины, поэтому export -> import -> export даёт побайтово стабильный результат. Импорт ограничен выбранной компанией и nest и сохраняет семантику ревизий и доставки, не публикуя черновики молча.

Путь чтения доставки выбирает одобренную ревизию и запрошенный язык (`en` или `ru`), а если перевод недоступен — одобренный канонический язык. Обратные ссылки строятся по нормализованным целям `[[slug]]`, `[[slug|alias]]` и `[[slug#anchor]]`. Поиск и доставка возвращают источник и идентификатор ревизии, чтобы потребитель мог объяснить происхождение результата.

## Границы

Слой API вызывает модуль, привязанный к компании; вызывающие стороны не передают произвольный nest для обхода границы компании. Предложения отделены от публикации и требуют явного решения принять или отклонить. Доставка знаний не заменяет путь утверждения wiki и временный recall Hindsight.

## Карта источников

- `server/src/myrmidon/knowledge/domain.ts` — типы, машины состояний, ссылки, выбор языка и правила одобрения.
- `server/src/myrmidon/knowledge/store.ts` — хранение ревизий, указатель доставки, экспорт/импорт и вызовы поиска.
- `server/src/myrmidon/knowledge/service.ts` — привязка компании и nest и подключение поиска PostgreSQL.
- `server/src/myrmidon/knowledge/mcp.ts` — инструменты MCP (`knowledge_write_draft` с `changeSummary` и `sources`).
- `server/src/myrmidon/knowledge/index.ts` — публичная поверхность модуля и начальные записи.
- `server/src/myrmidon/evals/knowledge-gate.ts` — интеграция с проверкой качества публикации.
- `ui/src/ui2/screens/knowledge/Ui2Knowledge.tsx` — компонент `RevisionsPanel`, отображающий примечания ревизий и ссылки на источники.
- `ui/src/ui2/screens/knowledge/knowledgeModel.ts` — интерфейсы `KnowledgeRevisionSummary` и `KnowledgeSourceRef`.
- `ui/src/ui2/screens/knowledge/knowledgeApi.ts` — разбор ответа API и сопоставление источников ревизии.
