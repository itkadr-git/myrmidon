# DOCS-CHAIN: Рунбук автоматизации цепочки документации

Цепочка документации выпуска 1.7 (эпик [OPE-12138](/OPE/issues/OPE-12138)) фиксирует сквозной регламент сопровождения документации и каталогов навыков при влитии изменений в основную ветку (`main`).

## 1. Назначение и триггеры

Цепочка запускается автоматически обработчиком webhook-доставки GitHub (`scripts/docs-chain/create-chain-tasks.mjs`) при условии:
- PR влит в ветку `main` (`action: closed`, `merged: true`, `base.ref: main`);
- PR изменяет файлы в отслеживаемых путях:
  - `docs/**`
  - `docs/wiki/**`
  - `.agents/skills/**`
  - `packages/skills-catalog/**`

Если PR не затрагивает ни одного из отслеживаемых путей, задачи цепочки не создаются (0 задач).

## 2. Фазы цепочки

1. **Фаза EN (EN docs task):**
   - Триггер: влитие любого PR в `main`, изменившего отслеживаемые пути.
   - Действие: создаётся задача на обновление английской документации и проверку дрейфа навыков.
   - Идемпотентный ключ: `docs-chain:<repo>:<pr>:en`.
   - Проверка: «доки и навык, дубль-проверка».
   - Исполнитель: инженер (роль `engineer`), задача берётся через очередь захвата, напрямую не назначается.

2. **Фаза RU (RU changed sections):**
   - Триггер: влитие PR фазы EN в `main`.
   - Действие: создаётся задача на перевод на русский язык **только изменённых разделов**.
   - Идемпотентный ключ: `docs-chain:<repo>:<pr>:ru`.
   - Обязательные поля: ссылка на исходный PR, список изменённых разделов.
   - Критерий приёмки: «переведены только изменённые разделы, ссылка на PR есть».
   - Исполнитель: инженер (роль `engineer`), задача берётся через очередь захвата.

## 3. Ограничения и правила безопасности

- **no auto-merge (автослияния нет):** Автослияние PR документации категорически запрещено. Любой PR цепочки проходит обязательное ревью человеком или ревьюером доски.
- **Ревью обязательно:** Каждый PR цепочки сдаётся через стадию `in_review` с назначенным участником ревью.
- **Лимит запусков на PR:** Не более 2 запусков агента на один PR для предотвращения зацикливания («лимит запусков: 2»).
- **Дедупликация:** Повторная доставка того же webhook payload повторно задачу не создаёт (0 задач). Идемпотентный ключ `docs-chain:<repo>:<pr>:<en|ru>` защищает от дублирования.

## 4. Шаблоны задач

### Шаблон: EN docs task

**Заголовок:** `1.7 DOCS-CHAIN EN: #{prNumber} {prTitle}`  
**Идемпотентный ключ:** `docs-chain:{repo}:{prNumber}:en`  
**Роль:** `engineer` (захват из очереди)

```markdown
Часть цепочки документации DOCS-CHAIN (выпуск 1.7).
EN docs task: обновление англоязычной документации и навыков по влитому PR.

- Исходный PR: {prUrl} (#{prNumber})
- Репозиторий: {repo}
- Изменённые пути:
{changedSections}

Цель:
1. Синхронизировать документацию (docs/**, docs/wiki/**) и каталоги навыков (.agents/skills/**, packages/skills-catalog/**) с изменениями кода.
2. Провести аудит дрейфа: доки и навык, дубль-проверка.

Правила:
- EN docs task
- Ревью обязательно
- Автослияния нет (no auto-merge)
- Лимит запусков на PR: 2
- Роль исполнителя: engineer (захват из очереди, без прямого назначения)

Критерии приёмки:
- Документация и навыки приведены в соответствие с исходным PR {prUrl}.
- Ссылка на исходный PR включена в описание PR.
- Автослияния нет.
```

### Шаблон: RU changed sections

**Заголовок:** `1.7 DOCS-CHAIN RU: #{prNumber} {prTitle}`  
**Идемпотентный ключ:** `docs-chain:{repo}:{prNumber}:ru`  
**Роль:** `engineer` (захват из очереди)

```markdown
Часть цепочки документации DOCS-CHAIN (выпуск 1.7).
RU changed sections: перевод на русский язык изменённых разделов по влитому PR.

- Исходный PR: {prUrl} (#{prNumber})
- Репозиторий: {repo}
- Список изменённых разделов:
{changedSections}

Цель:
1. Перевести на русский язык ТОЛЬКО изменённые разделы (docs/wiki, русскоязычные разделы документации).
2. Не вносить правок в неизменённые разделы во избежание шума и конфликтов.

Правила:
- RU changed sections
- Ревью обязательно
- Автослияния нет (no auto-merge)
- Лимит запусков на PR: 2
- Роль исполнителя: engineer (захват из очереди, без прямого назначения)

Критерии приёмки:
- переведены только изменённые разделы, ссылка на PR есть
- Ссылка на исходный PR {prUrl} сохранена в описании задачи и PR
- Автослияния нет.
```
