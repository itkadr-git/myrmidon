# Коннекторы и инструменты

> English version: [Connectors-and-tools](Connectors-and-tools)

Агенты работают через инструменты. Myrmidon держит опасную или тяжёлую
машинерию вне контейнера бота — как службы и шлюзы под управлением доски —
и выдаёт каждому боту ровно те инструменты, на которые он имеет право.

## Мост браузера

Мост браузера позволяет боту компании действовать в браузере на ПК клиента:
открывать страницы, читать, кликать, заполнять, скачивать, делать снимки
экрана и — по политике, заданной оператором, — участвовать в шаге подписания,
который человек завершает на этом ПК. На ПК клиента нет открытого порта:
расширение браузера само дозванивается **наружу** до шлюза коннекторов доски.
Панель коннекторов (Настройки компании → Коннекторы) — поверхность управления
оператора: сопряжение и отзыв устройств, белый список доменов, политика
подписания и журнал.

Раздел настроек «Браузеры» позволяет владельцу наблюдать и водить живые
браузеры, через которые боты входят на сайты: открыть сессию экрана,
поддерживать её, закрыть, очистить данные сайта.

## Коннекторы MCP

Доска может подключить совместимый со стандартом внешний сервер MCP — любой
HTTP endpoint MCP, который компания эксплуатирует или которому доверяет — и
передать его инструменты выбранным агентам, без изменения кода форка. На
собственном сервере MCP доски каждый инструмент публикуется под именем
`myrmidon*`; старые имена `paperclip*` продолжают работать как устаревшие
псевдонимы один выпуск, чтобы установленные системы не ломались.

## Облачные хранилища и Microsoft 365

Облачный коннектор делает облачное хранилище полноценным модулем доски:
владелец подключает один облачный аккаунт на провайдера с панели, и доступ к
папкам раздаётся агентам с того же места. Токен OAuth живёт в секретнице
экземпляра как секрет компании — боты его не видят.

Служба cloud-files даёт ботам-контейнерам OneDrive и общий почтовый ящик
одного служебного аккаунта Microsoft, за инструментальным шлюзом доски.

## Медиа, офис и OCR

Образ бота не несёт ни ffmpeg, ни LibreOffice, ни poppler, ни Tesseract. Они
живут в отдельных службах, а бот получает один адрес MCP. Путь OCR
превращает PDF, полученный ботом, — вложение письма, скачанный через мост
браузера файл, документ в рабочей области — в текст, с которым бот может
работать, плюс структурную выжимку для тендерной документации.

## GitHub

Агенты разработки пушат код через GitHub-брокер запуска: доска выдаёт запуску
учётные данные ровно на этот запуск. Компания может авторизовать GitHub один
раз на весь сервер своим собственным приложением GitHub App вместо
персональных OAuth-учёток.
