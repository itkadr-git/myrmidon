# Политика выполнения и настройки ленты внимания (1.6.6 SETTINGS-UI S)

> English version: [Instance-execution-policy-and-attention](Instance-execution-policy-and-attention)

В этом руководстве описаны бейдж политики выполнения (только для чтения) и панель настроек ленты внимания на странице **Settings > Instance > General** (аудит OPE-11230 / OPE-11234).

## Политика выполнения (`general.executionMode`)

### Описание и ограничения
Политика выполнения определяет целевую среду запуска агентов для экземпляра Myrmidon.
- **Расположение**: Отображается в верхней части страницы **Settings > Instance > General**.
- **Бейдж только для чтения**: Режим выполнения управляется на уровне платформы/облака и не может переключаться или редактироваться через пользовательский интерфейс. В интерфейсе он отображается в виде бейджа (`execution-mode-badge`).
- **Видимость**: Если параметр скрыт через конфигурацию инстанса (`hiddenSettings` содержит `instance.general.executionMode`), секция политики выполнения полностью скрывается из интерфейса.

### Режимы и поведение по умолчанию
- **`any`** (по умолчанию): Неограниченная среда выполнения. Агенты запускаются в стандартно настроенных окружениях.
- **`kubernetes`**: Принудительно направляет запуск всех агентов в управляемую песочницу Kubernetes.
- Если в `instance_settings.general` не задан явный режим, интерфейс по умолчанию отображает `any`.

## Настройки ленты внимания (`general.attention*`)

### Описание
Панель **Лента внимания** на странице **Settings > Instance > General** позволяет администраторам инстанса просматривать и изменять рабочие окна, используемые при формировании ленты внимания компании (`GET /api/myrmidon/attention-feed`).

### Хранимые настройки и границы
Настройки сохраняются в `instance_settings.general` и управляются через маршруты `GET`/`PATCH /api/myrmidon/attention-feed`:

| Настройка | Тип / Границы | Умолчание | Описание |
|---|---|---|---|
| `attentionFailedRunHorizonDays` | Целое число, от 1 до 365 | `7` | Горизонт поиска (в днях) неразрешённых упавших или превысивших таймаут прогонов для ленты внимания. |
| `attentionFeedCacheTtlSeconds` | Целое число, от 0 до 300 | `60` | Время жизни (в секундах) собранного снимка ленты внимания в оперативной памяти компании. `0` отключает кэширование. |

### Поведение в эксплуатации
- **Права доступа**: Читать настройки может любой участник доски; изменять — только администратор инстанса.
- **Частичное обновление**: `PATCH` поддерживает частичное обновление — изменение одного окна не затрагивает другое.
- **Аудит**: Каждое изменение параметров оставляет запись в аудите компании.
- **Применение без перезапуска**: Новые значения вступают в силу при следующей сборке ленты внимания; перезапуск процессов или повторный выкат не требуется.
