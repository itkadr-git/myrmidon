# Руководство по миграции знаний ADM (OPE-9263)

> English version: [Adm-knowledge-migration](Adm-knowledge-migration)


## Миграция

Команда `node scripts/myrmidon/adm-migrate.mjs SOURCE_ROOT` выполняет детерминированный тестовый прогон (dry-run) анализа устаревших источников знаний ADM (`CLAUDE.md` и каталога `memory/`). Исходные файлы при этом не изменяются.

Отчёт dry-run выводится в формате JSON и содержит:

- `manifest`: список путей исходных файлов и их хеши SHA-256.
- `report.counts`: разбивка по категориям (`rule`, `trigger`, `reference`, `lesson`, `skill_card`).
- `report.conflicts`: обнаруженные коллизии slug или содержимого.
- `report.oversized`: элементы, превышающие допустимые лимиты размера тела.
- `report.unrecognized`: файлы без указанной категории в индексе `MEMORY.md` или явном frontmatter.
- `report.missingSummary`: правила и триггеры без поля `description:` во frontmatter (фиксируется в отчёте в безопасном режиме без выбрасывания исключения).
- `report.redactions`: файлы с секретами, помещённые в карантин с помощью gitleaks.
- `report.secretsRemaining`: количество оставшихся секретов (для успешной проверки требуется 0).
- `report.sessionStartBytes` / `report.sessionStartLimit`: проверка бюджета сводки SessionStart (не более 12 КиБ).

Классификация определяется по заголовкам индекса `MEMORY.md` (например, `## Политики — всегда` для правил, `## Триггеры` для триггеров, `## Справочники` для справочников, `## Уроки` для уроков, `## Навыки` для карточек навыков) поверх плоского каталога `memory/*.md`. Обходчик автоматически пропускает подкаталоги `_archive/`.

Сканирование секретов использует gitleaks (версия >= 8.21 в `PATH` или через переменную `ADM_GITLEAKS_BIN`). При обнаружении шаблона секрета находка изолируется и регистрируется в отчёте.

## Верификация

В CI логика миграции проверяется тестом `node --test scripts/myrmidon/adm-migrate.test.mjs`:

- Реалистичный набор из 235 источников (плоский `memory/*.md`, индекс `MEMORY.md`, 15 политик + `CLAUDE.md` как правила).
- Извлечение `description:` из frontmatter и фиксация `report.missingSummary` без падения процесса.
- Пропуск каталога `_archive/` при обходе дерева.
- Обработка неиндексированных файлов через `report.unrecognized`.
- Проверка хеша SHA-256 закреплённого архива gitleaks и карантин секретов.
