# Пользователи инстанса (Instance users)

> English version: [Instance-users](Instance-users)

Экран «Пользователи инстанса» — это сквозной каталог пользователей по всем рабочим пространствам для администраторов инстанса. Он отделён от раздела «Настройки компании → Пользователи» (`/company/settings/users`): существующий экран управляет пользователями и приглашениями в выбранной компании, тогда как этот экран выполняет поиск по каталогу пользователей всего инстанса.

Откройте `/company/settings/instance/users`, чтобы перейти к экрану **Пользователи инстанса**. Пункт навигации отображается только администраторам инстанса. Страница читает результаты каталога через существующий API `accessApi.searchAdminUsers`; действий по управлению пользователями она не добавляет.

На странице отображается состояние загрузки во время выполнения поиска, пустое состояние, когда пользователи не найдены, и состояние ошибки при сбое запроса. Ответ 403 отображается как ошибка отказа в доступе, не раскрывая данных каталога. Пользователи, не являющиеся администраторами инстанса, не видят пункт навигации, а при прямом переходе по маршруту сервер сохраняет авторитарный контроль доступа.
