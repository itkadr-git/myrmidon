# Общий кэш пакетов для ботов контейнеров (1.6.1)

## Обзор
Функция общего кэша пакетов позволяет нескольким ботам разработки совместно использовать общие кэши пакетов (pnpm, pip, go, gradle) для уменьшения использования дискового пространства и повышения производительности. Вместо того чтобы каждый бот содержал свою собственную копию загруженных пакетов, они могут совместно использовать общий каталог кэша.

## Конфигурация
Общий кэш пакетов можно настроить через пользовательский интерфейс настроек экземпляра:

1. Перейдите в раздел "Настройки диска бота" в настройках экземпляра
2. Установите "Путь к общему кэшу пакетов" в каталог, доступный всем контейнерам ботов
3. Сохраните настройки

Альтернативно, настройки можно управлять через API по адресу `/api/myrmidon/bot-disk`.

## Поддерживаемые менеджеры пакетов
Функция в настоящее время поддерживает кэширование для:

- **pnpm**: Общее хранилище в `/.pnpm-store`
- **pip**: Общий кэш в `/.cache/pip`
- **Go**: Общий кэш сборки в `/.cache/go-build`
- **Gradle**: Общий кэш в `/.gradle`

## Техническая реализация
Когда настроено, контейнеры ботов будут иметь следующие точки монтирования:

- `${SHARED_CACHE_PATH}/pnpm:/home/user/.pnpm-store:rw`
- `${SHARED_CACHE_PATH}/pip:/home/user/.cache/pip:rw`
- `${SHARED_CACHE_PATH}/go:/home/user/.cache/go-build:rw`
- `${SHARED_CACHE_PATH}/gradle:/home/user/.gradle:rw`

Эти точки монтирования доступны для чтения и записи, чтобы менеджеры пакетов могли обновлять кэш новыми загруженными пакетами.

## Соображения безопасности
- Только определенные каталоги кэша разрешены для монтирования с правами на чтение и запись
- Обычные дополнительные точки монтирования остаются доступными только для чтения ради безопасности
- Dockergate проверяет, что только пути к кэшу могут использовать режим чтения-записи

## Преимущества
- **Снижение использования диска**: несколько ботов совместно используют одни и те же загрузки пакетов
- **Улучшенная производительность**: кэшированные пакеты не нужно повторно загружать
- **Стабильные сборки**: общий кэш обеспечивает согласованность версий пакетов

## Требования
- Доступ к Docker для контейнеров ботов
- Общее расположение файловой системы, доступное всем контейнерам ботов
- Соответствующие права доступа к каталогу общего кэша
