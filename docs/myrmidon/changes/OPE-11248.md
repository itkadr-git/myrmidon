## changelog-en

### Manage remaining inbox and agent access policies in settings (OPE-11248)

- Company member access now exposes the existing administrator-only inbox agent policy endpoint; agent trust settings expose visibility, assignment, and protected-agent assignment blocks. Blocking or unblocking assignments requires explicit confirmation. Existing trust preset and unrelated permissions remain intact.

## changelog-ru

### Управление оставшимися политиками доступа в настройках (OPE-11248)

- В настройках участника компании доступна существующая администраторская политика доступа агентов к inbox; в настройках доверия агента — видимость, назначение и блокировка назначения защищённого агента. Для блокировки и снятия блока требуется подтверждение. Существующие trust preset и прочие права сохраняются.
