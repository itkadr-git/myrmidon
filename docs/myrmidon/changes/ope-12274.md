**Native Runner Codex Sandbox & User Namespaces (OPE-12274):**
For native Codex execution (`paperclip_runner`), the Codex inner sandbox (`bwrap`) is intentionally **not** disabled. Disabling it would allow agents to read board container secrets. Instead, container runtimes must support unprivileged user namespaces (`userns`). The board container requires:
1. `--security-opt seccomp=path/to/myrmidon-board-userns.json` (custom seccomp profile allowing `clone, unshare, mount, umount2, pivot_root, setns`).
2. `--security-opt apparmor=unconfined` (to permit mount operations required by bwrap).
The runner now probes sandbox availability (`bwrap --unshare-user true`) before opening a Codex session. If user namespaces are unavailable, the run ends with a terminal `codex_sandbox_unavailable` result and fix guidance instead of an opaque bwrap namespace failure on `session.open`; runs in split mode also start with `notify` dispatch so the worker process executes them.

**Песочница нативного раннера Codex и User Namespaces (OPE-12274):**
Для нативного выполнения Codex (`paperclip_runner`) внутренняя песочница Codex (`bwrap`) намеренно **не** отключается (её отключение позволило бы агентам читать секреты контейнера доски). Вместо этого среда контейнера должна поддерживать непривилегированные user namespaces (`userns`). Контейнеру доски требуются:
1. `--security-opt seccomp=path/to/myrmidon-board-userns.json` (пользовательский seccomp-профиль, разрешающий `clone, unshare, mount, umount2, pivot_root, setns`).
2. `--security-opt apparmor=unconfined` (для разрешения операций монтирования, требуемых bwrap).
Раннер теперь проверяет доступность песочницы (`bwrap --unshare-user true`) до открытия сессии Codex. Если user namespaces недоступны, прогон завершается терминальной ошибкой `codex_sandbox_unavailable` с подсказкой по исправлению вместо непонятного падения bwrap на `session.open`; в split-режиме прогон по умолчанию стартует с диспетчеризацией `notify`, и исполняет его процесс worker.
