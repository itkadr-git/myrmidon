## changelog-en

### Native runner sandbox userns, run-dispatch improvements and settings docs

Added seccomp/userns Docker profile for sandbox support, updated run-dispatch dispatcher logic so API processes publish `run_queued` even in inline mode (role gate enforcement), and documented settings for user namespaces and run start dispatch.

## changelog-ru

### Песочница нативного раннера userns, улучшения диспетчера и документация настроек

Добавлен профиль seccomp/userns для Docker, обновлена логика диспетчера запуска (процессы API публикуют `run_queued` даже в режиме inline согласно ролевым ограничениям), а также добавлена документация по настройкам пользовательских пространств имен (userns) и диспетчеризации запуска прогонов.
