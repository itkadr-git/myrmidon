## changelog-en

### Guide: address any agent from one Telegram chat (TG-MULTI-AGENT)

- New operator guide
  [telegram-multi-agent](guides/telegram-multi-agent.md):
  `@`-mention addressing and the `/agents`, `/to`, `/who` commands of the
  bridged Telegram DM — aliases (`telegramAliases` in the agent card), the
  sticky default addressee (`telegramStickyAgentId`), and the protection
  rules (own bridged conversation only, same-company agents only, polite
  list of valid aliases for an unknown alias). X9a/X9b are already in main;
  X9c ships with the code PR.

## changelog-ru

### Руководство: любой агент из одной Telegram-лички (TG-MULTI-AGENT)

- Новое руководство оператора
  [telegram-multi-agent](guides/telegram-multi-agent.ru.md):
  адресация `@`-упоминанием и команды `/agents`, `/to`, `/who` мостовой
  лички Telegram — алиасы (`telegramAliases` в карточке агента), липкий
  адресат по умолчанию (`telegramStickyAgentId`) и правила защиты (только
  собственная мостовая переписка, только агенты своей компании, вежливая
  подсказка со списком алиасов при неизвестном алиасе). X9a/X9b уже в main;
  X9c выходит с кодовым PR.
