## changelog-en

### Re-scope shared bot runtime RO-layer to bin only (1.6.5-BOT-DISK-H11, OPE-12493)

- Exclude `lazy-packages` and `lsp` from `general.botDisk.sharedBotRuntimePath` read-only mounts. Only `bin` (~38 MB per bot, ~2.4 GB fleet-wide) is shared read-only across bots on the host. `lsp` is kept writable per bot and `lazy-packages` remains image-specific.
- Dockergate policy `BotRuntimeMounts` updated to accept only `bin`.

## changelog-ru

### Пересмотр общего RO-слоя среды ботов: только bin (1.6.5-BOT-DISK-H11, OPE-12493)

- Исключены `lazy-packages` и `lsp` из привязок на чтение настройки `general.botDisk.sharedBotRuntimePath`. Только подкаталог `bin` (~38 МБ на бота, ~2.4 ГБ по флоту) монтируется read-only. `lsp` остаётся записываемым внутри контейнера бота, а `lazy-packages` различается между образами.
- Политика dockergate `BotRuntimeMounts` обновлена: разрешён только `bin`.

## settings-en-replace

| `general.botDisk.sharedBotRuntimePath` | 1.6.5-BOT-DISK-H11 | unset (every bot has its own runtime) | Absolute host directory whose `bin` subdirectory every bot on the default host mounts read-only over its own runtime path in the container (`/bot/hermes/bin`), so one host copy replaces one copy per bot (~38 MB per bot, ~2.4 GB fleet-wide; re-scoped to bin-only in OPE-12493). The board adds the bind itself and checks it against the mounts of a card: a card cannot take the path over. Applies on the next reconcile pass, no restart. Bots on a fleetd host are not affected (logged once) | `null` or empty — off (every bot keeps its own copies). **Operator step:** create the `bin` subdirectory, move one bot's `bin` from its volume into it (it is the same files for every bot), own it by the image's user (uid/gid 10001) and set the same directory as `botRuntimeRoot` in the dockergate configuration ([dockergate.md](dockergate.md)), otherwise every runtime bind is refused with `mount_source_not_allowed`. Do not delete a bot's own copy before the setting is saved. See [bot-extra-mounts.md](bot-extra-mounts.md) |
