### 1.7 — Behavior settings API (runtime-settings, SETTINGS-TO-UI)

The Behavior Settings API provides runtime management of board settings without
requiring a server restart or downtime. Settings are declared in the behavior settings
registry (`packages/shared/src/myrmidon-behavior-settings.ts`) and applied dynamically
to the running process.

#### Precedence and Sources

Every setting's effective value is resolved using a three-tier precedence:
1. **`ui` (Stored value)**: An explicit value configured and saved by an operator via the API or UI.
   Stored in `instance_settings.general.behaviorSettings` for instance settings, or
   `instance_settings.general.behaviorSettingsByCompany[companyId]` for company settings.
2. **`env` (Environment variable)**: Value from the corresponding `MYRMIDON_*` environment variable,
   acting as the default for instances where no UI setting has been saved.
3. **`default` (Built-in default)**: Default value defined in the registry declaration when neither
   UI setting nor environment variable is set.

The API response returns both `settings` (effective resolved values) and `sources`
(the origin for each setting: `"ui"`, `"env"`, or `"default"`).

#### Scope and Scope Isolation

Each setting defines its `scope`:
- **`instance`**: Applies globally to the entire Myrmidon instance (e.g. `debug_mode`, `pause_drain_enabled`, `swarm_claim_enabled`).
- **`company`**: Applies per-company (e.g. `review_routing_enabled`).

**Scope Isolation:**
- Instance write endpoints (`PATCH /api/myrmidon/behavior-settings`, `PUT /api/myrmidon/behavior-settings`) only accept `instance`-scoped settings. Supplying a `company`-scoped setting results in `400 Bad Request`.
- Company write endpoints (`PATCH /api/myrmidon/behavior-settings/company/:companyId` and `PATCH /api/myrmidon/behavior-settings/:companyId`) only accept `company`-scoped settings. Supplying an `instance`-scoped setting results in `400 Bad Request`.

#### Endpoints and Formats

##### 1. List All Setting Definitions
- **Route:** `GET /api/myrmidon/behavior-settings/definitions`
- **Access:** Board members (`assertBoardOrgAccess`). Agents receive `403 Forbidden`.
- **Response:** JSON array of setting definitions:
  ```json
  [
    {
      "key": "pause_drain_enabled",
      "envName": "MYRMIDON_PAUSE_DRAIN_ENABLED",
      "default": true,
      "scope": "instance",
      "section": "kill_switches",
      "valueType": "boolean",
      "description": "Keep runs active during agent pause..."
    }
  ]
  ```

##### 2. Read Effective Instance Settings
- **Route:** `GET /api/myrmidon/behavior-settings` (or with query param `?key=:key`)
- **Access:** Board members (`assertBoardOrgAccess`). Agents receive `403 Forbidden`.
- **Response (All):**
  ```json
  {
    "settings": {
      "pause_drain_enabled": true,
      "debug_mode": false
    },
    "sources": {
      "pause_drain_enabled": "default",
      "debug_mode": "env"
    }
  }
  ```
- **Response (`?key=:key`):**
  ```json
  {
    "key": "pause_drain_enabled",
    "value": true,
    "source": "default",
    "definition": {
      "envName": "MYRMIDON_PAUSE_DRAIN_ENABLED",
      "default": true,
      "scope": "instance",
      "section": "kill_switches",
      "valueType": "boolean",
      "description": "..."
    }
  }
  ```
  Returns `404 Not Found` if the key is unknown.

##### 3. Read Single Setting by Path Key
- **Route:** `GET /api/myrmidon/behavior-settings/key/:key`
- **Access:** Board members (`assertBoardOrgAccess`). Agents receive `403 Forbidden`.
- **Response:** Single setting object with `key`, `value`, `source`, and `definition` (or `404 Not Found`).

##### 4. Update Instance Settings
- **Route:** `PATCH /api/myrmidon/behavior-settings` (and `PUT /api/myrmidon/behavior-settings` alias)
- **Access:** Instance Administrators only (`assertInstanceAdmin`). Non-admin board members and agents receive `403 Forbidden`.
- **Request Body:** Strict JSON object with setting key-value pairs:
  ```json
  {
    "pause_drain_enabled": false,
    "pause_drain_grace_sec": 240
  }
  ```
- **Response:** Updated effective instance settings object (`{ settings, sources }`).
- **Validation:**
  - Type checking (`boolean`, `number`, `string`, `json`).
  - Range validation (integers, min/max limits, floats, enums).
  - Scope check: only `instance`-scoped settings allowed (cross-scope writes return `400 Bad Request`).
  - Unknown keys return `400 Bad Request`.
- **Auditing:** Writes an activity log entry `instance.behavior_settings.updated` for every company on the instance.
- **Application:** Applies changes in-memory immediately without server restart.

##### 5. Read Company Settings
- **Route:** `GET /api/myrmidon/behavior-settings/company/:companyId` (and legacy alias `GET /api/myrmidon/behavior-settings/:companyId`)
- **Access:** Users with access to the specified company (`assertCompanyAccess`). Cross-company access receives `403 Forbidden`.
- **Response:** Company effective settings object (`{ settings, sources }`). Accepts optional `?key=:key` query parameter.

##### 6. Update Company Settings
- **Route:** `PATCH /api/myrmidon/behavior-settings/company/:companyId` (and legacy alias `PATCH /api/myrmidon/behavior-settings/:companyId`)
- **Access:** Users with access to the specified company (`assertCompanyAccess`). Cross-company access receives `403 Forbidden`.
- **Request Body:** Strict JSON object with company-scoped setting key-value pairs:
  ```json
  {
    "review_routing_enabled": false
  }
  ```
- **Response:** Updated effective company settings object (`{ settings, sources }`).
- **Validation:**
  - Value type and range validation.
  - Scope check: only `company`-scoped settings allowed (`instance`-scoped keys return `400 Bad Request`).
- **Auditing:** Writes an activity log entry `company.behavior_settings.updated` for the target company.
- **Application:** Applies changes in-memory immediately without server restart.

### 1.7 — API runtime-настроек (behavior-settings, SETTINGS-TO-UI)

API behavior-settings обеспечивает оперативное управление настройками доски в
рантайме без необходимости перезапуска сервера или простоя. Настройки объявляются в
реестре (`packages/shared/src/myrmidon-behavior-settings.ts`) и динамически
применяются к работающему процессу.

#### Приоритеты и источники значений

Действующее значение каждой настройки вычисляется по трёхзвенной схеме:
1. **`ui` (сохранённое значение)**: явное значение, сохранённое оператором через API или интерфейс.
   Хранится в `instance_settings.general.behaviorSettings` для настроек инстанса и в
   `instance_settings.general.behaviorSettingsByCompany[companyId]` для настроек компании.
2. **`env` (переменная окружения)**: значение соответствующей переменной окружения `MYRMIDON_*`,
   выступающее значением по умолчанию до первой записи оператора через UI/API.
3. **`default` (встроенное умолчание)**: значение из реестра настроек при отсутствии сохранённого значения и переменной окружения.

В ответах API возвращаются как вычисленные значения (`settings`), так и их источники (`sources`: `"ui"`, `"env"` или `"default"`).

#### Области видимости (Scope) и изоляция scope

Каждая настройка определяет свой уровень применения (`scope`):
- **`instance`**: действует глобально на весь инстанс доски (например, `debug_mode`, `pause_drain_enabled`, `swarm_claim_enabled`).
- **`company`**: настраивается индивидуально для конкретной компании (`review_routing_enabled`).

**Изоляция scope при записи:**
- Маршруты записи инстанса (`PATCH /api/myrmidon/behavior-settings`, `PUT /api/myrmidon/behavior-settings`) принимают только настройки со scope `instance`. Попытка записать настройку со scope `company` отклоняется с кодом `400 Bad Request`.
- Маршруты записи компании (`PATCH /api/myrmidon/behavior-settings/company/:companyId` и `/:companyId`) принимают только настройки со scope `company`. Попытка записать настройку со scope `instance` отклоняется с кодом `400 Bad Request`.

#### Маршруты API и форматы данных

##### 1. Метаданные определений настроек
- **Маршрут:** `GET /api/myrmidon/behavior-settings/definitions`
- **Права доступа:** Участники организации доски (`assertBoardOrgAccess`). Агенты получают `403 Forbidden`.
- **Формат ответа:** Массив JSON с метаданными всех настроек:
  ```json
  [
    {
      "key": "pause_drain_enabled",
      "envName": "MYRMIDON_PAUSE_DRAIN_ENABLED",
      "default": true,
      "scope": "instance",
      "section": "kill_switches",
      "valueType": "boolean",
      "description": "Не отменять активные прогоны агента при операторской паузе..."
    }
  ]
  ```

##### 2. Чтение действующих настроек инстанса
- **Маршрут:** `GET /api/myrmidon/behavior-settings` (или с query-параметром `?key=:key`)
- **Права доступа:** Участники организации доски (`assertBoardOrgAccess`). Агенты получают `403 Forbidden`.
- **Формат ответа (все настройки):**
  ```json
  {
    "settings": {
      "pause_drain_enabled": true,
      "debug_mode": false
    },
    "sources": {
      "pause_drain_enabled": "default",
      "debug_mode": "env"
    }
  }
  ```
- **Формат ответа (`?key=:key`):**
  ```json
  {
    "key": "pause_drain_enabled",
    "value": true,
    "source": "default",
    "definition": {
      "envName": "MYRMIDON_PAUSE_DRAIN_ENABLED",
      "default": true,
      "scope": "instance",
      "section": "kill_switches",
      "valueType": "boolean",
      "description": "..."
    }
  }
  ```
  При неизвестном ключе возвращается `404 Not Found`.

##### 3. Чтение отдельной настройки по пути
- **Маршрут:** `GET /api/myrmidon/behavior-settings/key/:key`
- **Права доступа:** Участники организации доски (`assertBoardOrgAccess`). Агенты получают `403 Forbidden`.
- **Формат ответа:** Объект с полями `key`, `value`, `source` и `definition` (или `404 Not Found`).

##### 4. Обновление настроек инстанса
- **Маршрут:** `PATCH /api/myrmidon/behavior-settings` (и алиас `PUT /api/myrmidon/behavior-settings`)
- **Права доступа:** Только администраторы инстанса (`assertInstanceAdmin`). Обычные пользователи и агенты получают `403 Forbidden`.
- **Тело запроса:** Строгий JSON-объект с парами ключ-значение:
  ```json
  {
    "pause_drain_enabled": false,
    "pause_drain_grace_sec": 240
  }
  ```
- **Формат ответа:** Обновлённый объект действующих настроек инстанса (`{ settings, sources }`).
- **Валидация:**
  - Проверка типов (`boolean`, `number`, `string`, `json`).
  - Проверка диапазонов (целочисленность, min/max, float, допустимые enum).
  - Проверка scope: разрешены только ключи со scope `instance` (кросс-скоуп ключи возвращают `400 Bad Request`).
  - Неизвестные ключи возвращают `400 Bad Request`.
- **Аудит:** Запись события `instance.behavior_settings.updated` в журнал активности для каждой компании.
- **Применение:** Изменения вступают в силу в памяти немедленно без перезапуска сервера.

##### 5. Чтение настроек компании
- **Маршрут:** `GET /api/myrmidon/behavior-settings/company/:companyId` (и легаси-алиас `GET /api/myrmidon/behavior-settings/:companyId`)
- **Права доступа:** Доступ к целевой компании (`assertCompanyAccess`). Доступ к чужим компаниям отклоняется с `403 Forbidden`.
- **Формат ответа:** Объект действующих настроек компании (`{ settings, sources }`). Поддерживается query-параметр `?key=:key`.

##### 6. Обновление настроек компании
- **Маршрут:** `PATCH /api/myrmidon/behavior-settings/company/:companyId` (и легаси-алиас `PATCH /api/myrmidon/behavior-settings/:companyId`)
- **Права доступа:** Доступ к целевой компании (`assertCompanyAccess`). Доступ к чужим компаниям отклоняется с `403 Forbidden`.
- **Тело запроса:** Строгий JSON-объект с настройками уровня компании:
  ```json
  {
    "review_routing_enabled": false
  }
  ```
- **Формат ответа:** Обновлённый объект действующих настроек компании (`{ settings, sources }`).
- **Валидация:**
  - Проверка типов и диапазонов значений.
  - Проверка scope: разрешены только настройки со scope `company` (instance-only ключи возвращают `400 Bad Request`).
- **Аудит:** Запись события `company.behavior_settings.updated` в журнал активности компании.
- **Применение:** Применение в памяти немедленно без перезапуска сервера.
