## changelog-en

### Bot runtime image: hermes 0.21.5 -> 0.23.1, delta rebase (OPE-12710)

- The bot runtime image pins hermes-agent `v0.23.1` (`3b42157858`), up from `v2026.9.24`
  (`0.21.5`); aiohttp follows the hermes extra to 3.14.5. From v0.22.0 upstream ships the
  release version in the annotated tag object instead of `pyproject.toml`, so the build's
  version check parses the tag body.
- The image base moves from `python:3.13-slim` to `python:3.14-slim`: since v0.23.1 the
  hermes lockfile requires `python_full_version >= '3.14'` (the `pm` subpackage pins
  `==3.14.*`), so `uv sync --frozen` failed outright on the old 3.13 base.
- Seven delta patches are dropped as upstream parity: 04 (locked-read retry),
  18/31 (terminal foreground heartbeat guard + its regression), 21 (session storage diet),
  23 (integrity-check lease file), 26 (compaction summary wire cap — upstream explicitly
  does not send a `max_tokens` cap on the summary call), 33 (summary sampling tool-pair
  grouping — upstream folds the pairing into its own `_sanitize_tool_pairs`; the oversized-record
  group bounding stays in the carried patch 32).
  24 patches remain; the plugin-catalog entry in v0.23.1 also raises the plugin download
  cap from 2 MiB to 16 MiB.

## changelog-ru

### Образ рантайма ботов: hermes 0.21.5 -> 0.23.1, ребейз дельт (OPE-12710)

- Образ рантайма ботов закреплён на hermes-agent `v0.23.1` (`3b42157858`) вместо
  `v2026.9.24` (`0.21.5`); aiohttp следует за extra hermes — 3.14.5. Начиная с v0.22.0
  апстрим кладёт версию релиза в тело аннотированного тега, а не в `pyproject.toml`,
  поэтому проверка версии в сборке разбирает тело тега.
- База образа сменилась с `python:3.13-slim` на `python:3.14-slim`: с v0.23.1 lockfile
  hermes требует `python_full_version >= '3.14'` (подпакет `pm` закрепляет `==3.14.*`),
  поэтому `uv sync --frozen` на старой базе 3.13 падал сразу.
- Семь дельт-патчей сняты как дублирующие апстрим: 04 (повтор при блокировке чтения),
  18/31 (guard foreground-heartbeat терминала + его регрессия), 21 (диета хранения сессий),
  23 (lease-файл integrity-check), 26 (wire-cap `max_tokens` у summary — апстрим
  намеренно не отправляет `max_tokens` в вызове summary), 33 (группировка tool-pair
  при сэмплировании summary — апстрим складывает пары в свой `_sanitize_tool_pairs`;
  групповое ограничение oversized-записи остаётся в сохранённом патче 32).
  Остаётся 24 патча; запись каталога плагинов в v0.23.1 также поднимает
  лимит скачивания плагина с 2 МиБ до 16 МиБ.
