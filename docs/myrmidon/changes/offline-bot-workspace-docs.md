## changelog-en

### Offline bot workspace registration

A board operator can reserve and register an existing standalone checkout on a managed persistent bot volume for a standard project issue. The workspace binding is checked again on swarm wake and fails closed if its identity changes. See the bot container workspace guide for prerequisites and verification.

## changelog-ru

### Офлайн-регистрация рабочей копии бота

Оператор доски может зарезервировать каталог и зарегистрировать существующую автономную копию на управляемом постоянном томе бота для стандартной проектной задачи. При пробуждении swarm привязка проверяется повторно; при изменении её идентичности запуск останавливается без fallback. Предварительные условия и проверка описаны в руководстве по рабочей копии контейнера бота.
