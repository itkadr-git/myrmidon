## changelog-en
### Owner-DM delivery filter, part B: the mode switch (OWNER-DM-FILTER)
- Company Settings has a new **Owner Telegram delivery** section. It picks which cards an agent raises are sent to the task owner's Telegram DM: **Owner decisions only** (the default — only the cards that wait for the owner) or **All cards** (everything, the behaviour before this change).
- The current mode is read with `GET /api/myrmidon/owner-delivery` and saved with `PATCH /api/myrmidon/owner-delivery` (`{ mode }`, instance administrator). A missing or unreadable setting shows `owner_decisions_only`.

## changelog-ru
### Фильтр owner-доставки, часть B: переключатель режима (OWNER-DM-FILTER)
- В настройках компании появился раздел **Owner Telegram delivery**. Он задаёт, какие карточки агентов уходят в ЛС владельца задачи в Telegram: **Owner decisions only** (по умолчанию — только карточки, которые ждут решения владельца) или **All cards** (все, как было до этого изменения).
- Текущий режим читается запросом `GET /api/myrmidon/owner-delivery` и сохраняется запросом `PATCH /api/myrmidon/owner-delivery` (`{ mode }`, instance admin). Если настройка отсутствует или не прочиталась, показывается `owner_decisions_only`.
