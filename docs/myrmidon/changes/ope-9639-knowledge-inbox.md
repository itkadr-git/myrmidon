## changelog-en

### Knowledge proposals in unified inbox and review routing (OPE-9639, KNOWLEDGE-2.0 L-1.1)

- Pending knowledge suggestions appear in the unified inbox (Streamlined UI and legacy Inbox) with `kind: "knowledge"`.
- Added the "Knowledge" category filter in the inbox filter popover with persistent selection and search.
- Selecting a knowledge inbox item routes to `/knowledge/review` for proposal inspection and disposition.

## changelog-ru

### Предложения знаний в едином inbox и маршрутизация на экран разбора (OPE-9639, KNOWLEDGE-2.0 L-1.1)

- Pending-предложения знаний отображаются в едином inbox (Streamlined UI и legacy Inbox) с типом `knowledge`.
- Добавлен фильтр типа «Знания» в выпадающем меню фильтрации inbox с сохранением выбранной категории и поддержкой поиска.
- Переход по элементу предложения знаний из inbox открывает экран разбора `/knowledge/review`.
