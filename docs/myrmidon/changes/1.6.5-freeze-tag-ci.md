## changelog-en

### Release freeze gate sees the tag CI (1.6.5)

- `scripts/myrmidon/release/release-freeze.sh` now selects the tag CI by
  `myrmidon-ci-tag.yml` runs with `head_branch == the tag` (the pipeline that
  runs on the tag itself), with `myrmidon-ci.yml` main-branch runs of the
  same commit kept as a fallback. Previously the gate filtered on
  `myrmidon-ci.yml` only, so the verdict stayed "missing" forever and the
  release freeze never cleared even with a green tag CI.

## changelog-ru

### Гейт заморозки релиза видит CI тега (1.6.5)

- `scripts/myrmidon/release/release-freeze.sh` теперь выбирает CI тега по
  раннам `myrmidon-ci-tag.yml` с `head_branch == тег` (конвейер, который
  работает на самом теге), а ранны `myrmidon-ci.yml` на main того же коммита
  оставлены запасным путём. Раньше гейт фильтровал только по
  `myrmidon-ci.yml`, вердикт навсегда оставался «missing» и заморозка релиза
  не снималась даже при зелёном CI тега.
