## changelog-en

### Forgotten-pause guard: the board lifts operator pauses left behind (1.6.5 PAUSE-GUARD)

- The board resumes, on its own, an agent that an operator paused and left
  paused longer than the threshold (20 minutes by default). The pause is the
  operator's own (`pause_reason = manual`); pauses the board sets for its own
  reasons — budget, archived company, import, a plugin note — are never
  touched. A resumed agent goes through the same wake chain the resume route
  uses, so its queued runs and its stranded `todo`/`in_progress` tasks come
  back to life instead of waiting for someone to notice.
- A pass resumes at most `maxResumesPerPass` agents (20 by default). The
  ceiling is what keeps a fleet-wide resume after a long night from starting
  every stranded backlog at the same instant: the remainder waits for the next
  pass and raises ONE notice per company on the attention desk, which
  disappears in the pass that finds nothing left over. Every resume is written
  to the activity log as `agent.pause_guard_resumed`.
- Settings live on the instance settings page next to "Run limits" (switch,
  threshold in minutes, interval in seconds, an allowlist of agent names, the
  per-pass ceiling) and change while the server runs — no restart, no run in
  flight is dropped. Saving re-arms the guard, so the next tick applies the new
  values. Names on the allowlist are never resumed: a maintenance window on a
  named agent is an operator decision, not a forgotten pause.
- This replaces the maintenance script that used to run from the host every 10
  minutes with a journal file and a fleet allowlist. The allowlist starts
  empty; the values an operator kept in the host file are moved in by hand.
- `MYRMIDON_PAUSE_GUARD_*` stays the default for an instance that has never
  saved the block; once saved, `instance_settings.general.pauseGuard` is the
  source of truth. The feature ships enabled: it is a defect fix (an operator
  pause that is forgotten is a stopped agent nobody decided to stop). See
  [SETTINGS.md](../SETTINGS.md).

## changelog-ru

### Страж забытых пауз: доска сама снимает оставленные паузы оператора (1.6.5 PAUSE-GUARD)

- Доска сама снимает агента, которого оператор поставил на паузу и оставил
  на ней дольше порога (по умолчанию 20 минут). Пауза — оператора
  (`pause_reason = manual`); паузы, которые доска ставит сама, — бюджет,
  архив компании, импорт, заметка плагина — не трогаются никогда. Снятый
  агент проходит ту же цепочку побудки, что и возобновление из интерфейса,
  поэтому его прогоны из очереди и зависшие задачи `todo`/`in_progress`
  возвращаются к работе, а не ждут, пока кто-нибудь заметит.
- За проход снимается не больше `maxResumesPerPass` агентов (по умолчанию 20).
  Потолок не даёт массовому снятию после длинной ночи поднять сразу весь
  зависший бэклог: остальные ждут следующего прохода и поднимают ОДНУ карточку
  внимания на компанию, исчезающую в том проходе, где ничего не осталось.
  Каждое снятие пишется в журнал действий как `agent.pause_guard_resumed`.
- Настройки — на странице настроек экземпляра рядом с «Run limits»:
  включение, порог в минутах, интервал в секундах, список имён-исключений,
  лимит за проход. Меняются на лету, без перезапуска и без потери идущих
  прогонов; сохранение перевзводит страж, поэтому новые значения применяются
  на ближайшем тике. Имена из списка не снимаются никогда: окно обслуживания
  на конкретном агенте — решение оператора, а не забытая пауза.
- Это замена хост-скрипта, который ходил по расписанию раз в 10 минут с файлом
  журнала и списком исключений флота. Список исключений по умолчанию пуст;
  значения, которые оператор держал в файле на хосте, переносятся вручную.
- `MYRMIDON_PAUSE_GUARD_*` остаётся умолчанием для экземпляра, который ни разу
  не сохранял блок; после первого сохранения источник истины —
  `instance_settings.general.pauseGuard`. Функция включена по умолчанию: это
  исправление дефекта (забытая пауза оператора — остановленный агент, которого
  никто не решал останавливать). См. [SETTINGS.ru.md](../SETTINGS.ru.md).

## settings-en

| `MYRMIDON_PAUSE_GUARD_ENABLED` | 1.6.5 PAUSE-GUARD | `1` (on) | Master switch of the forgotten-pause guard: the board resumes agents the operator paused and left paused longer than the threshold. | `MYRMIDON_PAUSE_GUARD_INTERVAL_SEC` | 1.6.5 PAUSE-GUARD | `600` | How often the guard looks for forgotten pauses, in seconds.
