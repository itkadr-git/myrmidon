## changelog-en

### Manual CI timeout smoke

- Added an isolated manual workflow for testing a self-hosted CI job timeout and a runbook for coordinated, single-dispatch evidence collection. A merged workflow alone does not establish that timeout or runner cleanup passed.

## changelog-ru

### Ручная проверка таймаута CI

- Добавлены отдельный ручной workflow для проверки таймаута CI job на self-hosted исполнителе и инструкция по согласованному сбору доказательств при одном запуске. Само слияние workflow не подтверждает таймаут или очистку исполнителя.
