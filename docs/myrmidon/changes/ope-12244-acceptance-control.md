## changelog-en

### Acceptance control fragment for OPE-12244

A throwaway fragment used to check that the docs reminder stays silent when a
pull request already ships a change fragment. It carries no product change and
is closed unmerged.

## changelog-ru

### Контрольный фрагмент приёмки OPE-12244

Временный фрагмент, нужный только для проверки: напоминание о доках молчит,
если в PR уже есть фрагмент изменений. Продуктовых изменений не несёт, PR
закрывается без слияния.
