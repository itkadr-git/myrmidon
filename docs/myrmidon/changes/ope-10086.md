## changelog-en

### Hot delivery of company skills without container restart (OPE-10086)

- Skill files (`hermes/skills/paperclip-managed/**`) are now classified as files-class changes (`filesHash`) rather than restart-class (`restartHash`).
- Modifying, adding, or removing company skills applies to the running bot container via live profile write without restarting the container or entering maintenance mode.
- In-progress runs are not interrupted by skill updates, and subsequent runs receive the updated skills per run.

## changelog-ru

### Горячая доставка навыков компании без перезапуска контейнера (OPE-10086)

- Файлы навыков (`hermes/skills/paperclip-managed/**`) теперь относятся к классу файлов (`filesHash`), а не перезапуска (`restartHash`).
- Изменение, добавление или удаление навыков компании доставляется в работающий контейнер бота горячей записью профиля без перезапуска контейнера и без входа в режим обслуживания.
- Идущие прогоны не прерываются при правке навыков, а новые прогоны видят обновлённую версию навыка.
