## changelog-en

### Clear git mirror toggle, effective defaults, and roles in bot disk settings (OPE-13116)

The bot disk settings panel now explicitly reflects the active git mirror state via a toggle switch, displays the effective list of repositories (with a "default" badge when using default configuration), and shows which roles receive the shared mirror. Turning the switch off explicitly clears mirrored repositories.

## changelog-ru

### Явный переключатель git-зеркала, список по умолчанию и роли в настройках bot disk (OPE-13116)

На экране настроек bot disk добавлен явный переключатель состояния git-зеркала, отображение действующего списка репозиториев (с пометкой «по умолчанию» при отсутствии сохранённого ключа) и строка ролей ботов, получающих общее зеркало. Выключение переключателя явно сохраняет пустой список.
