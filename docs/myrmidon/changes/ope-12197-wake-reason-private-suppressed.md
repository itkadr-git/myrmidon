## changelog-en

### Wake diagnostics name the private-task suppression reason (OPE-12197)

- A wake skipped because its issue is private to another agent is now shown with its own reason `heartbeat.private_issue_suppressed` instead of "other" in the issue wake diagnostics.

## changelog-ru

### В диагностике побудок видна причина «приватная задача» (OPE-12197)

- Побудка, пропущенная потому, что задача приватна для другого агента, теперь показывается в диагностике побудок задачи со своей причиной `heartbeat.private_issue_suppressed`, а не как «прочее».
