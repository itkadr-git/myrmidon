## changelog-en

Host cleanup now frees the task copies (worktrees, about 0.5 GB each) of every bot that is not the task's current assignee, not only reviewers: for example a lead that makes a full copy for each task it slices while engineers write the code. A copy is freed in any task status when the task has an assignee other than the bot, the bot has no live run of its own on the task, the copy was not touched for 10 minutes, `git status` is clean and HEAD is reachable from the server tip. The board is asked again right before the removal. The assignee's own copy and the copy of a task without an assignee are not touched by this rule. Journal events stay `review-clone-removed` / `review-clone-kept` with a `reason` field (`nonassignee-copy-idle`, `assignee`, `no-assignee`, `live-run`, ...).

## changelog-ru

Уборка хоста теперь освобождает копии задач (рабочие копии, около 0,5 ГБ каждая) любого бота, который не является текущим исполнителем задачи, а не только ревьюеров: например лида, который делает полную копию на каждую нарезанную задачу, пока код пишут инженеры. Копия освобождается при любом статусе задачи, если у задачи есть исполнитель, отличный от бота, у бота нет собственного живого прогона по задаче, копию не трогали 10 минут, `git status` чист, а HEAD достижим от серверной вершины. Перед удалением доска опрашивается ещё раз. Копия самого исполнителя и копия задачи без исполнителя этим правилом не затрагиваются. События журнала остаются `review-clone-removed` / `review-clone-kept` с полем `reason` (`nonassignee-copy-idle`, `assignee`, `no-assignee`, `live-run` и др.).
