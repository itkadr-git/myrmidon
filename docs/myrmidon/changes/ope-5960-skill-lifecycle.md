### 1.6 — SKILL-LIFECYCLE: жизненный цикл навыков компании

Параметры `server/src/myrmidon/skill-lifecycle/`. Навык компании имеет состояние
`candidate`, `verified` или `deprecated`. Навык со статусом `verified` доставляется
всем агентам; `candidate` — только пилотным агентам, остальные его не получают
(в профиле показывается предупреждение); `deprecated` не доставляется никому.
Если для навыка нет строки lifecycle, сохраняется прежнее поведение — он доступен
всем. Продвижение требует одобренной карточки типа `skill_promotion`; откат
восстанавливает предыдущую проверенную ревизию при следующей компиляции профиля.
Правила доставки не меняются этой настройкой.

Пилотный список по умолчанию читается из `MYRMIDON_SKILL_PILOT_AGENTS` — списка
ID агентов через запятую; пробелы вокруг ID удаляются. Пустое или незаданное
значение означает пустой список: кандидаты не доставляются ни одному агенту.
Для настройки на уровне компании используйте UI/API жизненного цикла:
`GET /api/myrmidon/companies/:companyId/skill-lifecycle/pilot-agents` показывает
эффективные ID и источник (`setting` или `env`), а
`PUT /api/myrmidon/companies/:companyId/skill-lifecycle/pilot-agents` принимает
`{"agentIds":["<agent-id>"]}`. Пустой массив явно отключает пилот для компании.
Чтение требует доступа к компании; изменение доступно только оператору доски.

| Переменная | Функция | По умолчанию | Что делает | Как выключить / особое |
|---|---|---|---|---|
| `MYRMIDON_SKILL_PILOT_AGENTS` | SKILL-LIFECYCLE | не задана (пустой список) | ID агентов через запятую, которым доступны навыки `candidate`, если для компании не задан собственный список | Пусто — кандидаты никому не доставляются; настройка компании в UI/API позволяет выбрать пилотный список |
