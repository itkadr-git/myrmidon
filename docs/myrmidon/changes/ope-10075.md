# OPE-10075: DEVFLOW pipeline liveness metrics and alerts (stale marker, stalled merge, stalled router)

## Motivation

The DEVFLOW release outage identified critical stages where automation can stall silently without alerts:
1. An APPROVE review decision is reached on the board, but the PR marker (`review-approved`) is missing or stale on GitHub.
2. A PR is approved with passing CI, but auto-merge has not merged it.
3. The review router scheduler or queue is stalled, leaving review tasks unrouted without a reviewer.

This change adds persisted, observable age metrics and actionable, automatically recovering alerts to DEVFLOW health monitoring for each of these stages.

## What Changed

- **Thresholds & settings** (`server/src/myrmidon/devflow-health/thresholds.ts`):
  - Added `staleMarkerMs`, `stalledMergeMs`, and `stalledRouterMs` to `DEFAULT_DEVFLOW_THRESHOLDS_MS` (default 60 minutes each).
  - Supported aliases: `approvalMarkerMs`, `autoMergeMs`, and `reviewRouterMs`.
  - Added timestamp snapshots and duration collectors for all three new stages in `collectDevflowDurations`.

- **Pure decision & recovery logic** (`server/src/myrmidon/devflow-health/signals.ts`):
  - `staleMarkerSince`: detects missing or stale `review-approved` markers on open PRs after an APPROVE verdict. Automatically recovers (returns `null`) when the marker is applied, head matches, or the PR is merged/closed.
  - `stalledMergeSince`: detects open PRs with approvals that remain unmerged beyond threshold. Automatically recovers when the PR merges, closes, or approval is revoked.
  - `stalledRouterSince`: detects unrouted review issues in `in_review` without a reviewer. Automatically recovers when a reviewer is assigned or the issue transitions out of `in_review`.

- **Persisted health collector** (`server/src/myrmidon/devflow-health/collector.ts`):
  - Evaluates `issueExecutionDecisions` and review comments (`parseReviewReworkVerdictMarkers`) to identify APPROVE verdicts.
  - Checks PR metadata (`reviewApproved`, `reviewApprovedAt`, `labels`) and connection event deliveries for `review-approved`.
  - Evaluates unrouted issues in `in_review` using `issueNeedsReviewer`.
  - Added environment variable overrides: `MYRMIDON_DEVFLOW_STALE_MARKER_MS`, `MYRMIDON_DEVFLOW_STALLED_MERGE_MS`, `MYRMIDON_DEVFLOW_STALLED_ROUTER_MS` (and their aliases).

- **Automated tests** (`server/src/myrmidon/devflow-health/thresholds.myrmidon.test.ts`, `server/src/myrmidon/devflow-health/signals.myrmidon.test.ts`):
  - Threshold boundaries, aliases, defaults, and snapshot collection for all six stages.
  - Stale marker detection, stale timestamp detection, head mismatch detection, and recovery.
  - Stalled auto-merge detection and merge/close recovery.
  - Stalled router detection and reviewer assignment recovery.
