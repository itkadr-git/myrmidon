## changelog-en

### 1.6.5 F-26 T3 — castes become configurable, agents get nests (CASTES-AND-NESTS)

- Castes: `agent_castes.is_default` with a partial unique index per company
  (migration `0385_agent_castes_default_and_nests`, index
  `agent_castes_company_default_uq`; backfill to `engineer`, otherwise the first
  key). The catalogue moves the flag in one transaction on
  `PATCH /api/myrmidon/companies/:id/castes/:key {isDefault:true}`; clearing the
  flag on its holder answers `409 caste_default_required`, and deleting the
  default caste requires `reassignTo` — the flag moves to the target together
  with its agents.
- Nests: the table `agent_nests(company_id, agent_id, project_id)` and
  `GET/PUT /api/myrmidon/companies/:id/agents/:agentId/nests` — the project list
  of one agent, empty meaning the whole company. A foreign project or a foreign
  agent is rejected as a whole (400/404), the write goes into the company
  journal.
- Matcher ports in `server/src/myrmidon/castes/index.ts`:
  `resolveTaskCaste(db, {companyId, issueId})` (task caste → project default →
  company default) and `agentNests(db, agentId)`, plus the SQL fragments
  `taskCasteKeySql` / `agentNestsAllowSql` for a one-query filter — the contract
  T1 builds on. Castes are no longer hard-coded in the swarm logic: `AGENT_ROLES`
  is not read there, the 12 vendor roles are seeded as the default caste and
  marked "template" in the UI.
- UI: the default radio and the agent/queue/free counters on the castes screen,
  the nests section on the agent card, IA v2 routes (`…/settings/castes`,
  `…/settings/models`; the old `caste-directory` redirects) and i18n keys in
  every locale.

## changelog-ru

### 1.6.5 F-26 T3 — касты стали настраиваемыми, у агентов появились гнёзда (CASTES-AND-NESTS)

- Касты: `agent_castes.is_default` с частичным уникальным индексом на компанию
  (миграция `0385_agent_castes_default_and_nests`, индекс
  `agent_castes_company_default_uq`; бэкфилл на `engineer`, иначе первая по
  ключу). Каталог переносит флаг одной транзакцией по
  `PATCH /api/myrmidon/companies/:id/castes/:key {isDefault:true}`; снятие флага
  с держателя отвечает `409 caste_default_required`, а удаление дефолтной касты
  требует `reassignTo` — флаг уходит цели вместе с её агентами.
- Гнёзда: таблица `agent_nests(company_id, agent_id, project_id)` и
  `GET/PUT /api/myrmidon/companies/:id/agents/:agentId/nests` — список проектов
  одного агента, пусто означает всю компанию. Чужой проект или чужой агент
  отвергается целиком (400/404), запись попадает в журнал компании.
- Порты сопоставителя в `server/src/myrmidon/castes/index.ts`:
  `resolveTaskCaste(db, {companyId, issueId})` (каста задачи → дефолт проекта →
  дефолт компании) и `agentNests(db, agentId)`, плюс SQL-фрагменты
  `taskCasteKeySql` / `agentNestsAllowSql` для фильтра одним запросом — контракт,
  на который опирается T1. Касты больше не зашиты в логике роя: `AGENT_ROLES`
  там не читается, 12 вендорских ролей засеваются дефолтной кастой и помечены
  в интерфейсе как «шаблон».
- Интерфейс: радио дефолта и счётчики «агентов / очередь / свободно» на экране
  каст, секция «Гнёзда» в карточке агента, маршруты IA v2
  (`…/settings/castes`, `…/settings/models`; старый `caste-directory`
  редиректит) и ключи i18n во всех локалях.

## settings-en

| `MYRMIDON_CONTINUATION_MESSAGE_CHARS` | DB-CARE DBC-3 | `32000` | Character budget of the `messages` list of the run continuation envelope: `MYRMIDON_CONTINUATION_HISTORY_LIMIT` bounds the number of entries, this bounds their total size, and the resume delta counts against the same budget. A body that no longer fits goes in as a reference (a stub with `bodyOmitted`); the full text stays in the task thread | `0` — only the entry cap applies. Unset, empty, non-numeric or negative — the default. Read from the process environment, there is no live settings row |
| `MYRMIDON_CONTINUATION_MESSAGE_BODY_CHARS` | DB-CARE DBC-3 | `8000` | Per-body budget applied once the total budget is exceeded: a body longer than this is shortened with an ellipsis, the full text stays in the task thread | Unset, empty, non-numeric or negative — the default. Read from the process environment, there is no live settings row |
