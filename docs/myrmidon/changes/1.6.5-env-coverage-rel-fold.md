# 1.6.5: env names orphaned by the release fragment fold

The release cut folds and removes the change fragments that documented these
settings; they are documented here so the env coverage guard
(`server/src/myrmidon/flags-killswitch.myrmidon.test.ts`) sees them until the
final SETTINGS.md fold.

Settings:

- `MYRMIDON_CONTINUATION_MESSAGE_CHARS` — total character budget of the
  `messages` array in the execution-continuation envelope; `0` disables the
  budget (entry cap still applies). Default: 32000.
- `MYRMIDON_CONTINUATION_MESSAGE_BODY_CHARS` — per-message body budget applied
  once the total budget is exceeded; oversized bodies are replaced by a
  reference (`bodyOmitted`), the body stays in the task thread. Default: 8000.
- `MYRMIDON_BOT_SCOPE_SUBDIR` — name of the per-scope subdirectory the bot
  container driver passes to member bots (bot-isolation scope mounts; the
  scope store lives inside the instance's single mount). Internal driver
  contract: set by the driver, not an operator setting.
