## changelog-en

### Live console scratch cleanup

The live console browser server now removes the temporary working directory it creates when it closes or fails to start. Caller-provided directories are left untouched.

## changelog-ru

### Очистка временного каталога live console

Браузерный сервер live console теперь удаляет созданный им временный каталог при закрытии или неудачном запуске. Каталоги, переданные вызывающим кодом, не затрагиваются.
