## changelog-en

### Skills Store: discover skills and check delivery (SKILLS-UI)

- Documented discovery from an agentskills.io site, SHA-256-verified archive
  imports, required environment names and role-scoped use of existing secrets.
- Added guidance for interpreting discovery/import errors, checking delivery for
  a selected agent, and using the separate Apps MCP connector path. Documentation
  does not claim provider account, balance, or general runtime acceptance.

## changelog-ru

### Каталог навыков: поиск и проверка доставки (SKILLS-UI)

- Описаны обнаружение навыков на сайте agentskills.io, импорт архивов с
  проверкой SHA-256, требуемые переменные окружения и доступ роли к уже
  существующим секретам.
- Добавлены пояснения к ошибкам обнаружения и импорта, проверке доставки для
  выбранного агента и отдельному пути подключения MCP через Apps. Документация
  не утверждает, что проверены аккаунт провайдера, баланс или runtime в целом.
