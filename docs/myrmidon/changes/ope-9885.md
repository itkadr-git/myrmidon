### 1.6.6 — DEVFLOW: devflow health alert thresholds

Environment variable overrides for attention-feed DEVFLOW alert thresholds (in milliseconds), configured under `instance_settings.general.devflowHealth`. Zero alerts immediately; invalid, negative or nonfinite values fall back to defaults.

| Variable | Function | Default | What it does | How to disable / special |
|---|---|---|---|---|
| `MYRMIDON_DEVFLOW_ENGINEER_IDLE_MS` | DEVFLOW-HEALTH | `3600000` (1 h) | Age threshold in milliseconds for idle engineer alerts. Engineers with role `engineer` and status `idle` aged from `lastHeartbeatAt` (or `createdAt`) raise an alert when idle duration exceeds this threshold. | Non-negative integer (ms). Unset, negative or invalid falls back to default (`3600000`). `0` alerts immediately. |
| `MYRMIDON_DEVFLOW_REVIEW_QUEUE_MS` | DEVFLOW-HEALTH | `86400000` (24 h) | Age threshold in milliseconds for review queue alerts. Tasks in `in_review` aged from the latest transition into `in_review` raise an alert when review duration exceeds this threshold. | Non-negative integer (ms). Unset, negative or invalid falls back to default (`86400000`). `0` alerts immediately. |
| `MYRMIDON_DEVFLOW_RED_CI_MS` | DEVFLOW-HEALTH | `3600000` (1 h) | Age threshold in milliseconds for red CI alerts on pull requests. A failed CI run on an active issue's PR raises an alert when red duration exceeds this threshold. | Non-negative integer (ms). Unset, negative or invalid falls back to default (`3600000`). `0` alerts immediately. |

### 1.6.6 — DEVFLOW: пороги оповещений devflow health

Переменные окружения для переопределения порогов оповещений DEVFLOW в ленте внимания (в миллисекундах), настраиваемые в `instance_settings.general.devflowHealth`. Ноль вызывает немедленное оповещение; невалидные, отрицательные или нечисловые значения откатываются к значениям по умолчанию.

| Переменная | Функция | По умолчанию | Что делает | Как отключить / особенности |
|---|---|---|---|---|
| `MYRMIDON_DEVFLOW_ENGINEER_IDLE_MS` | DEVFLOW-HEALTH | `3600000` (1 ч) | Порог возраста в миллисекундах для оповещения о простое инженера. Агенты с ролью `engineer` и статусом `idle`, отсчитываемые от `lastHeartbeatAt` (или `createdAt`), вызывают оповещение при превышении порога. | Неотрицательное целое (мс). Не задано, отрицательное или невалидное откатывается к `3600000`. `0` оповещает сразу. |
| `MYRMIDON_DEVFLOW_REVIEW_QUEUE_MS` | DEVFLOW-HEALTH | `86400000` (24 ч) | Порог возраста в миллисекундах для очереди ревью. Задачи в статусе `in_review`, отсчитываемые от последнего перехода в `in_review`, вызывают оповещение при превышении порога. | Неотрицательное целое (мс). Не задано, отрицательное или невалидное откатывается к `86400000`. `0` оповещает сразу. |
| `MYRMIDON_DEVFLOW_RED_CI_MS` | DEVFLOW-HEALTH | `3600000` (1 ч) | Порог возраста в миллисекундах для красного CI в pull request. Упавший прогон CI по PR активной задачи вызывает оповещение при превышении порога. | Неотрицательное целое (мс). Не задано, отрицательное или невалидное откатывается к `3600000`. `0` оповещает сразу. |
