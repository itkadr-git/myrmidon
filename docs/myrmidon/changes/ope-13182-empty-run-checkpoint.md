## changelog-en

### Empty runs by agent on the team liveness card (OPE-13182)

- The company health card shows positive empty-run counts per full agent ID for the existing window, ordered by count descending and ID ascending. With no positive counts it displays an empty state. This is read-only and does not change execution or pauses.

## changelog-ru

### Пустые прогоны по агентам на карточке Team liveness (OPE-13182)

- Карточка здоровья компании показывает положительные числа пустых прогонов по полному ID агента за существующее окно: сначала большее число, при равенстве ID по возрастанию. Если положительных значений нет, показано сообщение. Это отображение только для чтения; выполнение и паузы не меняются.
