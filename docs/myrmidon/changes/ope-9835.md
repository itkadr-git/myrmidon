## settings-en-new

### 1.6.6 — DEVFLOW: approved not merged and no merges alert thresholds

Environment variable overrides for attention-feed DEVFLOW alert thresholds (in milliseconds), configured under `instance_settings.general.devflowHealth`:

| Variable | Function | Default | What it does | How to disable / special |
|---|---|---|---|---|
| `MYRMIDON_DEVFLOW_APPROVED_NOT_MERGED_MS` | DEVFLOW-HEALTH | `7200000` (2 h) | Age threshold in milliseconds for approved pull requests remaining unmerged. | Non-negative integer (ms). Unset, negative or invalid falls back to default (`7200000`). `0` alerts immediately. |
| `MYRMIDON_DEVFLOW_NO_MERGES_MS` | DEVFLOW-HEALTH | `21600000` (6 h) | Duration threshold in milliseconds when active PR queue is non-empty and 0 merges have occurred. | Non-negative integer (ms). Unset, negative or invalid falls back to default (`21600000`). `0` alerts immediately. |

## settings-ru-new

### 1.6.6 — DEVFLOW: пороги оповещений для утверждённых PR и отсутствия слияний

Переменные окружения для переопределения порогов оповещений DEVFLOW в ленте внимания (в миллисекундах), настраиваемые в `instance_settings.general.devflowHealth`:

| Переменная | Функция | По умолчанию | Что делает | Как отключить / особенности |
|---|---|---|---|---|
| `MYRMIDON_DEVFLOW_APPROVED_NOT_MERGED_MS` | DEVFLOW-HEALTH | `7200000` (2 ч) | Порог возраста в миллисекундах для утверждённых pull request, остающихся не слитыми. | Неотрицательное целое (мс). Не задано, отрицательное или невалидное откатывается к `7200000`. `0` оповещает сразу. |
| `MYRMIDON_DEVFLOW_NO_MERGES_MS` | DEVFLOW-HEALTH | `21600000` (6 ч) | Порог длительности в миллисекундах при непустой очереди активных PR и отсутствии слияний. | Неотрицательное целое (мс). Не задано, отрицательное или невалидное откатывается к `21600000`. `0` оповещает сразу. |
