## changelog-en

### COLLECT-FRAGMENTS: support line-number-prefixed table rows in SETTINGS replacements (OPE-10778)

- `scripts/myrmidon/release/collect-fragments.mjs` recognizes rows with line number prefixes (e.g. `240i|`) as table rows, allowing replacement of upstream line-prefix artifacts via `settings-ru-replace`.

## changelog-ru

### COLLECT-FRAGMENTS: поддержка строк таблиц с префиксами номеров строк в замене SETTINGS (OPE-10778)

- `scripts/myrmidon/release/collect-fragments.mjs` распознаёт строки с префиксами номеров (например, `240i|`) как строки таблицы, позволяя заменять артефакты префиксов строк через `settings-ru-replace`.
