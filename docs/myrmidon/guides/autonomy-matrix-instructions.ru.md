# Матрица автономии: Контроль изменения инструкций

Матрица автономии контролирует, какие действия может выполнять каждая роль агента без участия человека. В этом руководстве объясняется, как класс действий `change_instructions` управляет изменениями инструкций агентов.

## Обзор

Начиная с версии 1.6.2, матрица автономии включает класс действий `change_instructions`, который регулирует:

- Изменение пути инструкций агента (`PATCH /agents/:id/instructions-path`)
- Обновление пакета инструкций агента (`PATCH /agents/:id/instructions-bundle`)
- Удаление файлов из пакета инструкций агента (`DELETE /agents/:id/instructions-bundle/file`)
- Откат ревизий инструкций агента (`POST /agents/:id/config-revisions/:revisionId/rollback`)

## Классы действий

Класс действий `change_instructions` контролирует модификацию основных инструкций агента. Когда агент пытается изменить свои собственные или чужие инструкции, система проверяет матрицу автономии, чтобы определить, разрешено ли действие, требует ли оно одобрения или запрещено.

### Типы решений

Каждой паре (роль, класс действия) в матрице присваивается одно из трех возможных решений:

- **`allowed`**: Агент может изменять инструкции без вмешательства человека
- **`approval_required`**: Действие приостанавливается до одобрения человеком (функция в разработке)
- **`forbidden`**: Агенту запрещено изменять инструкции (возвращается 403)

## Точки контроля

Матрица автономии применяется в четырех ключевых маршрутах:

1. `PATCH /api/agents/:id/instructions-path`
2. `PATCH /api/agents/:id/instructions-bundle`
3. `DELETE /api/agents/:id/instructions-bundle/file`
4. `POST /api/agents/:id/config-revisions/:revisionId/rollback`

Для каждого из этих маршрутов, если роль запрашивающего агента имеет решение `forbidden` для класса действий `change_instructions`, система возвращает ответ 403 Forbidden с кодом ошибки `autonomy_forbidden`.

## Конфигурация

Настройте матрицу автономии через интерфейс доски или API. Матрица содержит:

- Правила, указывающие сопоставления (роль, класс действия) → решение
- Значения по умолчанию для классов действий без специфических правил
- Отслеживание версий для управления конкурентным доступом

## Доступ доски

Пользователи доски (люди) не подчиняются ограничениям матрицы автономии и всегда могут изменять инструкции агентов независимо от конфигурации матрицы.
