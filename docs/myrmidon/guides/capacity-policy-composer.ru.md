# Компоновщик порядка кандидатов capacity policy

`packages/shared` экспортирует `orderCandidatesWithPolicy` из `myrmidon-capacity-policy-order.js` для объединения этапов capacity policy в очереди кандидатов. Функция принимает список кандидатов, флаг `enabled`, параметры политики и необязательные реализации-провайдеры `CapacityPolicyPorts`. По умолчанию используются проверки capacity, защита от голодания и справедливое распределение по проектам из `myrmidon-capacity-policy.ts`.

Если `enabled` равен `false`, кандидаты сохраняют канонический порядок `orderSwarmQueueCandidates`, а список `rejected` пуст. При включённой политике компоновщик сначала проверяет лимиты; отклонённый кандидат получает причину, например `project_limit` или `caste_limit`. Затем применяются продвижение ожидающих задач и справедливое распределение по проектам. Итоговая сортировка учитывает эффективный приоритет, позицию fairness, score и исходную позицию в очереди. Компаратор не меняет глобальные ранги приоритетов swarm. Для отсутствующего `createdAt` используется существующий безопасный fallback.

Это общая утилита упорядочивания; сам факт её экспорта не включает и не планирует production-развёртывание capacity policy. Для операционных изменений используйте существующую конфигурацию политики и утверждённую процедуру выката.
