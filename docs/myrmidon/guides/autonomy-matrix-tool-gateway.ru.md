# Интеграция матрицы автономии в шлюз инструментов

## Обзор

Матрица автономии контролирует, какие действия агенты могут выполнять, на основе их роли. С этой интеграцией конкретные вызовы инструментов теперь классифицируются по классам действий (`merge`, `deploy`, `external_message` и т.д.) и проверяются на соответствие матрице автономии перед выполнением.

## Классы действий

В матрице автономии определены следующие классы действий:

- `merge` - Операции с pull request и Git
- `deploy` - Действия, связанные с деплоем
- `external_message` - Коммуникации, отправляемые за пределы системы (email, Slack и т.д.)
- `spend_above_threshold` - Финансовые транзакции
- `delete` - Операции удаления
- `pause_wake_agents` - Управление жизненным циклом агентов
- `change_instructions` - Изменения инструкций агентов
- `other` - Все остальные инструменты без явного сопоставления

## Классификация инструментов

Инструменты сопоставляются с классами действий с использованием настраиваемой системы сопоставления. По умолчанию предоставляются сопоставления для распространенных инструментов:

- **Инструменты слияния**: `github.create_pr`, `github.merge_pr`, `git.push` и т.д.
- **Инструменты деплоя**: `deploy.apply`, `kubernetes.deploy`, `vercel.deploy` и т.д.
- **Инструменты внешних сообщений**: `email.send`, `slack.send_message`, `notification.send` и т.д.

## Точки контроля

Матрица автономии проверяется в шлюзе инструментов когда:

1. Агент пытается выполнить инструмент
2. Инструмент сопоставлен с классом действий
3. Роль агента имеет конкретный вердикт для этого класса действий

## Обработка вердиктов

- `allowed` - Инструмент выполняется нормально
- `approval_required` - Выполнение инструмента приостанавливается и создается запрос на одобрение
- `forbidden` - Выполнение инструмента запрещено с ошибкой 403 и кодом `autonomy_forbidden`

## Конфигурация

Сопоставление инструментов с классами действий настраивается через константу `DEFAULT_TOOL_AUTONOMY_MAPPING` и может быть расширено пользовательскими сопоставлениями.

## Тестирование

Каждый вердикт матрицы автономии тестируется для обеспечения правильного контроля:

- Запрещенные действия вызывают ошибки 403
- Действия, требующие одобрения, создают запросы на одобрение
- Разрешенные действия выполняются нормально
- Инструменты без сопоставления продолжают работать как раньше
