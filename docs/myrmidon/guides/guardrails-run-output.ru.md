# Ограничения и редактирование вывода guardrail

myrmidon(1.6-GRD): перед записью событий проверка вывода run ограничена.

- Сканируются только первые 262 144 символа финального текста run.
- Для одного run записывается не более 20 событий guardrail. Итоговые числа
  детектирования остаются в возвращаемом результате, а лимит записи защищает
  хранилище событий.
- Сохраняемые фрагменты ограничены 200 символами и редактируются по форме до
  записи. Сырые адреса электронной почты и значения, похожие на токены, не
  должны попадать в запись события.
- Функция остаётся только флагом; этот дельта не добавляет и не меняет режимы
  enforcement, порядок resolver, фильтры или элементы UI.

Регрессионные тесты покрывают границу сканирования, лимит событий, редактирование
формы и ограничение длины фрагмента. Линия mode/resolver/filter/UI поставляется
отдельно в PR #513 и намеренно здесь не дублируется и не переписывается.

## Настройка

Существующий переключатель `MYRMIDON_GUARDRAILS_OUTPUT_ENABLED` включает или
выключает hook для вывода run. Лимиты являются защитными границами кода, а не
настройками рантайма.
