# Консоль серверов

> English version: [server-console.md](server-console.md)

«Server console» — раздел на странице настроек компании (маршрут
`company/settings`, раздел «Server console» ниже настроек команды), который
открывает терминал сервера флота прямо в браузере владельца — для моментов,
когда на сервере флота нужны руки: проверить службу, прочитать журнал,
поправить зависший процесс.

Сам терминал — Apache Guacamole; доска не поднимает и не ставит клиент
Guacamole — его разворачивает эксплуатация и сообщает доске его адрес. Доска
держит реестр узлов, выдаёт одноразовые входные токены для Guacamole, пишет
журнал и держит каждый секрет на сервере: ничего постоянного в браузер не
попадает, а пароль узла не покидает подписанный токен.

## Кто что может

Только владелец компании — пользователь доски с активной ролью владельца в
компании, администратор инстанса или локальный неявный актор — читает реестр,
регистрирует узлы, открывает консоли и закрывает сессии. Участники и агентские
API-ключи получают 403 на любой вызов раздела.

## Реестр узлов

Реестр держит по строке на сервер флота. В каждой строке:

- **Name key** (slug) — короткий идентификатор в нижнем регистре, уникальный
  внутри компании (стиль `node-a`: `^[a-z0-9][a-z0-9-]{0,62}$`);
- **Display name** — подпись, которую показывают список и консоль;
- **Host** и **Port** — адрес узла; порт можно оставить пустым — тогда берётся
  порт протокола по умолчанию (22 для ssh, 5900 для vnc);
- **Protocol** — `ssh` для шелла, `vnc` для графической консоли;
- **Node user** — учётная запись, под которой входит консоль; пусто — берётся
  `fleet-console` по умолчанию;
- **Password secret key** — имя секрета компании (Access hub → Secrets) с
  паролем узла. Пусто — вход на узел по ключу. Реестр хранит только имя
  секрета; значение пароля читает сервер в момент выдачи токена, и оно не
  попадает ни в ответ, ни в журнал, ни в браузер.

Узел регистрируется формой «Register a node» внизу раздела. Повторная
регистрация с уже существующим name key заменяет поля той строки — та же форма
служит для правки адреса, протокола или ссылки на секрет узла. Строку реестра
можно выключить (`enabled` off): выключенный узел остаётся в списке, а его
кнопка Console неактивна. Реестр живёт в базе (таблица
`myrmidon_fleet_servers`, добавленная аддитивной миграцией) и ведётся по
компаниям: каждая компания видит только свои узлы.

Реестр и журнал работают и вовсе без настроенного адреса консоли; только
открытие консоли требует эксплуатационной настройки ниже.

## Открытие консоли

Нажмите **Console** в строке узла. Доска:

1. Проверяет, что вы владелец компании, а узел включён;
2. Собирает одноразовый входной документ для Guacamole, подписывает и
   шифрует его общим ключом и пишет выдачу в журнал;
3. Показывает терминал Guacamole этого узла во фрейме внутри раздела (плюс
   ссылку **Open in a new tab** на тот же адрес).

Токен короткоживущий: он действует 5 минут с момента выдачи, и панель
показывает обратный отсчёт («Token expires in … s»). Открывайте терминал сразу
— после истечения срока Guacamole токен не принимает, и просроченный токен
означает новое нажатие Console ради свежего токена. Браузер получает только
зашифрованный блок; пароль узла едет внутри него шифротекстом.

Открытие консоли на другом узле при уже открытой сначала закрывает прежнюю
сессию (её запись в журнале получает длительность), а затем выдаёт новый
токен.

По окончании работы нажмите **Close session** — запись в журнале получает
длительность сессии.

## Журнал

Каждое использование консоли записывается в журнал активности доски (экран
активности компании):

- `myrmidon.console.token_issued` — кто открыл консоль, когда, на каком узле,
  по какому протоколу и когда истекает токен;
- `myrmidon.console.session_closed` — закрытие, с длительностью сессии.

Ни токен, ни общий ключ, ни пароль узла в журнал не попадают — только
идентификатор сессии и перечисленные факты.

## Что должна предоставить эксплуатация

Работе Console нужны две вещи вне доски:

- `MYRMIDON_FLEET_CONSOLE_URL` — базовый адрес клиента Guacamole, под которого
  доска подписывает токены (например, `https://guac.example.com`, без
  завершающего `/`), заданный в окружении доски. Не задан или пуст — нажатие
  Console отвечает `503 console_not_configured`; реестр и журнал при этом
  работают. Читается при старте сервера, так что смена значения требует
  перезапуска.
- Секрет компании с именем `guacamole-json-secret-key` — общий ключ доски и
  клиента Guacamole (то же значение, что у клиента в `json-secret-key`).
  Значение должно быть 32 шестнадцатеричными символами (128 бит).
  Отсутствующий секрет отвечает `503 console_secret_missing`; значение в
  другом формате — `503 console_secret_invalid`: доска отказывается, а не
  выдаёт токен, который Guacamole отвергнет. Значение читает только сервер, и
  оно не попадает ни в ответ, ни в журнал.

Строка узла, ссылающаяся на отсутствующий в хранилище секрет с паролем,
отвечает `503 console_node_secret_missing`; выключенный узел —
`409 console_server_disabled`; неизвестный узел —
`404 console_server_not_found`.

## Программный интерфейс

Базовый путь `/api/myrmidon/fleet`; все четыре маршрута требуют владельца
компании (иначе 403, агентские ключи — 403):

```text
GET  /api/myrmidon/fleet/servers?companyId=          — реестр узлов
PUT  /api/myrmidon/fleet/servers                     — зарегистрировать или заменить строку узла
POST /api/myrmidon/fleet/console-token               — выдать 5-минутный токен Guacamole
POST /api/myrmidon/fleet/console-sessions/close      — закрыть сессию (записывает длительность)
```

## Настройки

Единственная переменная окружения описана в
[../SETTINGS.md](../SETTINGS.md), раздел «SC1 — server console
(SERVER-CONSOLE, 1.4)»: `MYRMIDON_FLEET_CONSOLE_URL`. Общий ключ и пароли
узлов — секреты компании, а не переменные окружения.

## Известные ограничения этой части

- У консольной сессии нет таймаута бездействия на стороне доски: по окончании
  работы нажимайте **Close session** — без этого журнал хранит только запись о
  выдаче, без длительности. Сам токен по-прежнему истекает через 5 минут.
- Запись сессии (`recording-path` Guacamole) этой частью не настраивается:
  свидетельство о том, кто пользовался консолью, — журнал доски.
- Создание учётной записи `fleet-console` на самих узлах и размещение их
  паролей в хранилище секретов — задачи эксплуатации, доской не выполняются.
