# API загрузки и валидации пользовательских каталогов локализации

API загрузки каталогов локализации позволяет владельцам инстанса и участникам совета загружать собственные файлы переводов (JSON), валидировать структуру и ключи относительно эталонного каталога `en`, а также хранить каталоги с автоматическим версионированием и контрольными суммами.

## Эндпоинты

### 1. Загрузка каталога
- **Маршрут**: `POST /api/myrmidon/locales/upload` (алиас: `POST /api/myrmidon/locale-upload`)
- **Доступ**: только участники совета (`assertBoard`)
- **Формат**: `multipart/form-data` (поле `file` или `catalog`) или `application/json`
- **Параметры тела (JSON)**:
  - `locale`: идентификатор локали (например, `de`, `fr`, `es-mx`)
  - `catalog`: объект с переводами (словарь ключей)
  - `dryRun` (опционально, boolean): валидация без сохранения в базу
  - `strict` (опционально, boolean): строгий режим (требует наличия всех базовых ключей)
- **Ответ**: `UploadLocaleResult` (код 200) или ошибка с дифференциальным отчётом (код 400)

### 2. Валидация каталога без сохранения
- **Маршрут**: `POST /api/myrmidon/locales/validate`
- **Доступ**: только участники совета (`assertBoard`)
- **Ответ**: 200 с `{ valid: true, report, warnings }` или 400 с `{ error: "CATALOG_VALIDATION_FAILED", report, errors, warnings }`

### 3. Список загруженных каталогов
- **Маршрут**: `GET /api/myrmidon/locales/custom`
- **Доступ**: аутентифицированные пользователи
- **Ответ**: список метаданных загруженных каталогов (версия, дата, число ключей, контрольная сумма)

### 4. Получение каталога
- **Маршрут**: `GET /api/myrmidon/locales/custom/:locale`
- **Доступ**: аутентифицированные пользователи
- **Ответ**: полные данные сохранённой локали с JSON каталога

### 5. Удаление каталога
- **Маршрут**: `DELETE /api/myrmidon/locales/custom/:locale`
- **Доступ**: только участники совета (`assertBoard`)
- **Ответ**: `{ deleted: true, locale }` (код 200) или 404

## Правила валидации
- Корневой элемент должен быть JSON-объектом (вложенные ключи разворачиваются через точку: `app.title`).
- Плейсхолдеры: переменные интерполяции `{var}` и `{{var}}` должны строго совпадать с эталонным каталогом `en`.
- Запрещённый контент: теги `<script>`, inline обработчики событий (`onload=`, `onclick=`), `javascript:` и `data:` URI блокируются.
- Длина строки: не более 4000 символов на перевод.
