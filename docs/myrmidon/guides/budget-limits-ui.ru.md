# Лимиты расхода по уровням: экран владельца (1.7 BUDGET-CONFIG D)

> Английская версия: [budget-limits-ui.md](budget-limits-ui.md)

Экран «Бюджеты» — это место, где владелец задаёт и меняет лимиты расхода
[иерархии](budget-limits.ru.md) и видит расход относительно лимита на каждом
уровне. Он живёт в текущем интерфейсе доски: **Настройки компании → Бюджеты**
(`/company/settings/budgets`), код — `ui/src/components/myrmidon/budget-limits/`.

## Дерево

Одна строка на уровень — те же тройки `(компания, уровень, ref)`, что хранит API:

| Уровень | Какие строки показывает экран |
|---|---|
| Гнездо | вся компания и по строке на каждый проект компании |
| Каста | по строке на каждую касту с лимитом (новая добавляется по ключу роли) |
| Фуражировка | единственный проход фуражировки |
| Задача | по строке на каждую задачу с лимитом (новая добавляется по идентификатору задачи) |

В каждой строке — сумма, период (`Календарный месяц (UTC)` или `За всё
время`), режим (`Жёсткий: отказ` или `Мягкий: пауза и карточка`) и расход
периода против лимита: `$600.00 / $500.00 (120% израсходовано)`, а при
превышении — пометка **Сверх лимита**. Строка без лимита говорит «Нет
лимита» — владелец задаёт его тут же.

Правка идёт на месте: меняете сумму, период или режим и нажимаете
**Сохранить** в этой строке. **Создать** записывает первый лимит строки, у
которой его нет; **Удалить** снимает сохранённый лимит (история остаётся в
журнале). Каждое сохранение уходит прямо в работающий API — без перезапуска
и без перезагрузки страницы: строка, расход и запись журнала обновляются с
сервера.

## Только сигнал

Переключатель в верхней части экрана — это глобальный режим, которым владеет
владелец: пока он включён, пересечение лимита только сигналит и ничего не
блокирует. Экран показывает и действующее значение, и **откуда оно взялось**:

- *Значение по умолчанию — ничего не сохранено* — режим включён, потому что
  выбор никто не сохранял;
- *Сохранено в настройках* — выбор владельца;
- *Задано переменной окружения — переключатель заблокирован* — переменная
  окружения сильнее, переключатель выключен, чтобы устаревшая вкладка не
  перезаписала значение (имя переменной — в [budget-limits.ru.md](budget-limits.ru.md)).

Переключатель сохраняется через `PATCH …/budget-limits/signal-only` (только
доска) и применяется сразу.

## Журнал изменений

Нижняя таблица — журнал лимитов: когда, кто (идентификатор актора), что
сделали (создан / изменён / удалён), какой уровень и значение, и как
изменилась сумма («Было $500.00, стало $750.00»). Журнал только дополняется,
новые записи сверху — удалённый лимит оставляет свои строки.

## Кто что видит

- Читатели с доступом к компании видят дерево, расход и журнал.
- Мутации (сумма, период, режим, удаление, «только сигнал») требуют актора
  доски; без этого права API их отклоняет, а экран показывает причину.
