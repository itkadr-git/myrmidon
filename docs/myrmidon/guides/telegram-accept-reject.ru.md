# Команды Telegram для принятия/отклонения планов

Это руководство описывает новые команды Telegram, которые позволяют владельцам принимать или отклонять планы непосредственно из чата Telegram.

## Команды

### `/accept <id>`
Принимает карточку плана с указанным ID, создавая соответствующий эпик и задачи.

- Использование: `/accept <id-взаимодействия>`
- Ответ: Подтверждение с ссылкой на созданный эпик и количеством задач

Пример:
```
/accept abc123def456
```

### `/reject <id>`
Отклоняет карточку плана с указанным ID, отменяя её без создания задач.

- Использование: `/reject <id-взаимодействия>`
- Ответ: Подтверждение, что карточка была отклонена

Пример:
```
/reject abc123def456
```

## Как это работает

1. Когда план предлагается через чат CTO, на постоянной задаче беседы создается карточка `suggest_tasks`
2. ID карточки можно использовать с командами `/accept` или `/reject`
3. `/accept` подтверждает все задачи карточки через тот же вызов сервиса `acceptInteraction`, что и маршрут портала — эпик и дочерние задачи создаёт код доски
4. `/reject` закрывает карточку со статусом `rejected` через тот же вызов сервиса `rejectInteraction`, что и маршрут портала — задачи не создаются
5. Обе команды проверяют, что пользователь имеет право действовать с карточкой

## Безопасность

- Только владелец Telegram-беседы может принимать/отклонять карточки (проверка контекста команды из X8c: команда действует только в собственном чате вызывающего)
- Карточки проверяются, чтобы убедиться, что они принадлежат правильной компании и задаче
- Только ожидающие карточки `suggest_tasks` могут быть приняты/отклонены

## Точки интеграции

- Использует существующий тип взаимодействия `suggest_tasks`
- Использует `issueThreadInteractionService.acceptInteraction` / `rejectInteraction` — тот же сервис доски, что и эндпоинты принятия/отклонения портала, без второй реализации
- Интегрируется с инфраструктурой моста Telegram DM (раннер команд X8c)
