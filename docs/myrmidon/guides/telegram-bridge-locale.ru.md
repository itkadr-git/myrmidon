# Telegram-мост: служебные тексты по языку пользователя (TG-LOCALE)

> English version: [telegram-bridge-locale.md](telegram-bridge-locale.md)

Бриджевая личка Telegram (включается для эндпоинта переменной
`MYRMIDON_TELEGRAM_DM_CONVERSATIONS`) отвечает на языке привязанного
пользователя доски. Ответы команд (`/help`, `/model`, `/think`, `/stop`,
`/status`, `/plan`), отказы («этот чат недоступен», отказ непривязанному
аккаунту), уведомление о переходе и прочие служебные тексты берутся из
файлов локализации на сервере, а не из литералов в коде.

## Как выбирается язык

По убыванию приоритета:

1. **Принуждение окружением** — `MYRMIDON_TELEGRAM_DM_LANGUAGE=en|ru`
   ставит один язык для всего экземпляра: для всех чатов и для меню команд
   Telegram. Это переопределение для оператора, штатная работа env не
   требует. Любое другое значение игнорируется.
2. **Ваш выбор** — язык, сохранённый на экране «Настройки → Язык» доски
   (строка `user_ui_language` пользователя). Он читается заново при каждом
   сообщении, поэтому смена языка видна боту уже в следующем ответе: без
   перезапуска и без переподключения.
3. **Английский** — язык форка по умолчанию для тех, кто не выбирал, и для
   аккаунтов Telegram, не привязанных к пользователю доски (отказ
   непривязанному приходит по-английски, с учётом принуждения env).

## Меню команд Telegram

Telegram показывает одно меню личных чатов на бота, а не на пользователя,
поэтому меню следует только решению экземпляра: принуждение env, если
задано, иначе английский. Личные ответы при этом следят языку каждого
пользователя.

## Источник значения

Экран «Настройки → Язык» показывает под выбором, следует ли бот Telegram
вашей настройке или закреплён переменной окружения сервера (с названием
закреплённого языка). Источник пересчитывается при каждом чтении, поэтому
экран правдив без перезапуска. Ту же строку настройки пишет переключатель
языка в меню аккаунта текущего интерфейса — обе поверхности задают одно
значение.

## Раскладка каталогов

- `server/src/myrmidon/agent-chat-bridge/locales/en.ts` — базовый каталог
  (английский; все ключи определены здесь).
- `server/src/myrmidon/agent-chat-bridge/locales/ru.ts` — русский, паритет
  ключей с английским (держится тестом; плейсхолдеры тоже совпадают).
- `server/src/myrmidon/agent-chat-bridge/locales/index.ts` — выбор локали и
  рендер `t(locale, key, params)`.

Тест-храповик (`locales-ratchet.myrmidon.test.ts`) валит CI, если кириллический
строковый литерал появится в коде моста вне каталогов, — новый служебный текст
не может молча bypass локализацию. Идентификаторы — не проза: имена команд,
модели и уровни рассуждений не переводятся.

## Настройки

| Переменная | Значение | По умолчанию |
|---|---|---|
| `MYRMIDON_TELEGRAM_DM_LANGUAGE` | Принудительно ставит `en` или `ru` для всех текстов бриджевой лички и меню команд, на весь экземпляр | не задана — по настройке пользователя с английским по умолчанию |
