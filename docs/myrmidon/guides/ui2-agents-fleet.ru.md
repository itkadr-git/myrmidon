# Флот агентов в UI-2

Экран «Флот агентов» UI-2 доступен по адресу `/{company}/agents` и использует API агентов с областью видимости компании. Для каждого агента отображаются имя, роль, текущее состояние (`idle`, `running` или `error`) и последний активный прогон, если он есть. Агенты вложены в дерево согласно полю `reportsTo`; контейнер прокрутки обеспечивает удобную работу с большими списками на компьютере и телефоне. Выбор агента открывает страницу его карточки и чата.

Пункт перехода присутствует по одному разу в навигации настольной и мобильной версий под названием «Agents» («Агенты»); пункт «Servers» («Серверы») открывает отдельный экран хостов и служб `/fleet`. Если агенты не настроены, страница отображает локализованное пустое состояние.

Экран опрашивает список агентов каждые 30 секунд, а активные прогоны — каждые 15 секунд. Запрос данных о прогонах ограничен параметрами `minCount=50&limit=100` вместо выгрузки всей истории heartbeat.

Если агент возвращает статус `paused`, интерфейс сохраняет и отображает его как отдельное состояние, не подменяя на статус ожидания (`idle`).
