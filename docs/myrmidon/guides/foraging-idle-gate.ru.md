# Гейт простоя фуражировки (myrmidon 1.6.3 FORAGING-IDLE-GATE)

## Что делает

Правило продукта: **обучение только в простое**. Перед тем как проход
фуражировки читает источники роли, проход проверяет, что роль простаивает:

- очередь роли пуста — в компании нет открытых задач `todo`/`in_progress`,
  ожидающих **без исполнителя** (семантика очереди роя: задача, уже
  назначенная агенту роли, выполняется, она не «ждёт в очереди»);
- есть хотя бы один свободный агент роли — за ним не закреплено ни одной
  задачи `todo`/`in_progress`.

Занятая роль **пропускается в этом проходе**: её источники не читаются, а
результат прохода и журнал несут причину:

| причина            | смысл                                                        |
| ------------------ | ------------------------------------------------------------ |
| `queue_not_empty`  | у роли есть неназначенные открытые задачи в ожидании          |
| `no_idle_agent`    | каждый агент роли занят задачей todo/in_progress              |

Гейт действует **по роли внутри одного прохода**: занятая роль инженера
никогда не мешает sweep прочитать источники роли smm в том же проходе. Проход
никогда не обрывается из-за гейта.

## Переключатель

Гейт включён по умолчанию. Это значение страницы настроек —
`instance_settings.general.foragingIdleGate` — меняется через:

```
GET   /api/myrmidon/foraging/idle-gate     (чтение board; отвечает {enabled, source})
PATCH /api/myrmidon/foraging/idle-gate     (instance admin; тело {enabled: boolean})
```

Проход **перечитывает переключатель на каждом проходе**, поэтому изменение
на странице настроек действует на следующий проход без перезапуска сервера.
`GET` отвечает действующее значение и его источник:

- `settings` — сохранённое значение (`general.foragingIdleGate`);
- `env` — принудительное переопределение `MYRMIDON_FORAGING_IDLE_GATE_ENABLED`
  (для инстанса, где значение ни разу не сохраняли; `1/true/on/yes` = вкл,
  `0/false/off/no` = выкл, остальное читается как «не задано»);
- `default` — ничего не сохранено и в env пусто: включено.

Приоритет: сохранённое значение; затем env; затем встроенное значение. Нечитаемое
сохранённое значение считается отсутствующим, а ошибка чтения настроек
срабатывает «открыто» (гейт остаётся включённым) — временная ошибка БД не
может заблокировать фуражировку в состояние, которого никто не просил.

Другие связанные параметры (без изменений этой фичей):

- `MYRMIDON_FORAGING_ENABLED`: общее включение фуражировки
- `MYRMIDON_FORAGING_BUDGET_CENTS`: потолок стоимости на проход
- `MYRMIDON_FORAGING_INTERVAL_SEC`: интервал проходов в секундах

## Информация о результате

Результат прохода фуражировки содержит поле `skippedReason`, когда роль была
пропущена из-за гейта:

- `queue_not_empty`: у роли есть неназначенные задачи в очереди
- `no_idle_agent`: у роли нет свободного агента
- Отсутствует: у всех включённых источников роли простаивали (или гейт выключен)

## Где живёт код

- `packages/shared/src/myrmidon-foraging-idle-gate.ts` — контракт резолвера
  (ключ, приоритет, источники), общий с сервером;
- `server/src/myrmidon/foraging/idle-gate-settings.ts` — сервис настроек
  (чтение/обновление/аудит) и чтение на каждом проходе;
- `server/src/myrmidon/foraging/idle-gate-routes.ts` — GET/PATCH роуты;
- `server/src/myrmidon/foraging/service.ts` — гейт в `runPass`
  (`createDbForagingIdleCheck`: SQL проверки очереди и свободного агента);
- тесты: `service.myrmidon.test.ts` (три критерия приёмки, фильтрация по
  роли, перечитывание без пересоздания сервиса),
  `idle-gate-settings.myrmidon.test.ts` (сервис настроек),
  `packages/shared/src/myrmidon-foraging-idle-gate.test.ts` (резолвер).
