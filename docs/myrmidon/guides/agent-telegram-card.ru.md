# Поля Telegram на карточке агента

> English version: [agent-telegram-card.md](agent-telegram-card.md)

На карточке агента есть раздел **Telegram** (под блоком гнёзд), где оператор
доски видит и меняет ровно то, чем пользуется Telegram-мост: как адресовать
этого агента и под какой группой `/agents` подаёт его карточку. До этого
раздела оба значения можно было задать только руками через API.

Оба значения лежат в JSON `metadata` карточки агента:

- `telegramAliases` — список строк, псевдонимы, на которые мост отвечает;
- `telegramGroup` — свободный текст, название группы, под которым список
  `/agents` группирует карточку.

Сохранение идёт через существующий `PATCH /api/agents/{agentId}` с телом
`metadata`: раздел сначала перечитывает агента и меняет только два ключа
Telegram, поэтому остальные ключи метаданных не теряются при сохранении.

## Псевдонимы

- Строки псевдонимов редактируются: введите новый в поле и нажмите **Add**
  (или Enter); строка снимается крестиком ✕ рядом с ней.
- Псевдоним — **строчными латинскими буквами, цифрами и подчёркиванием**,
  тот же алфавит, что резолвит мост (`adm-dev-eng-15` → `15`). Черновик с
  другими символами или дубликат уже имеющейся строки блокируется с ошибкой
  на месте и не сохраняется.
- Сопоставление в мосту не зависит от регистра, и в `/to`/`@`-упоминаниях
  псевдоним работает и с `@`, и без — см.
  [telegram-multi-agent.ru.md](telegram-multi-agent.ru.md).

### Псевдоним по умолчанию

Пока список псевдонимов пуст, раздел называет **псевдоним по умолчанию,
который мост считает из имени агента**: последний сегмент имени после
дефиса, приведённый к нижнему регистру, только латиница/цифры/подчёркивание
(`adm-dev-eng-15` → `15`, `Wiki Maintainer` → `wikimaintainer`). Хвост вовсе
без латиницы не даёт умолчания — карточка сообщает об этом и предлагает
добавить псевдоним.

Это удобство на чтение: в карточку ничего не пишется, явный псевдоним всегда
сильнее, а вычисленный никогда не затеняет имя другого агента или чужой
явный псевдоним (коллизия получает суффикс `-2`, `-3`, … по всей компании, в
порядке имён).

## Группа

Строка **Telegram group** хранит название группы, под которым список
`/agents` показывает карточку (`metadata.telegramGroup`). Поле подсказывает
уже существующие группы компании через datalist, чтобы агенты попадали в ту
же группу без перепечатывания. Пустое значение группирует карточку по
префиксу имени (встроенные группы моста `adm*`/`bbq*`/`work*`/прочие).

## Что делает сохранение

- Немедленное, на каждое изменение — мост перечитывает карточку при
  следующем проходе, рестарт или перекат не нужны.
- Патч метаданных строится от свежего GET агента и трогает только
  `telegramAliases` и `telegramGroup`: снятие всех строк псевдонимов удаляет
  ключ (мост снова считает умолчание), пустая группа удаляет этот ключ.
