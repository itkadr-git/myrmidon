# Режимы применения ограждений, настройки и журнал UI

myrmidon(1.7-GRD-MODES): настраиваемые режимы применения правил ограждений (`flag`, `mask`, `block`) с иерархией разрешения, горячим чтением настроек без перезапуска и фильтруемым журналом срабатываний.

## Режимы применения

Каждая категория ограждений (`secret`, `pii`, `injection`) поддерживает три режима:

- **flag** (по умолчанию): обнаруживает совпадение и фиксирует событие в журнале ограждений. Текст вывода и ввода публикуется без изменений.
- **mask**: заменяет совпавшие фрагменты на `[masked]` перед публикацией или постановкой комментария в очередь.
- **block**: полностью блокирует вывод прогона или добавление комментария. Для вывода прогона вместо ответа публикуется безопасное сообщение об отказе (`[Guardrail block: content withheld by policy]`), предотвращающее утечку секретов или персональных данных. При инъекции в очереди комментариев операция отклоняется с ошибкой `GUARDRAIL_INJECTION_BLOCKED`.

## Порядок разрешения (прецедент)

Действующий режим вычисляется по строгой иерархии:

1. **Принудительное переопределение окружения**: переменные `MYRMIDON_GUARDRAILS_FORCE_MODE_<RULE>` (например, `MYRMIDON_GUARDRAILS_FORCE_MODE_SECRET=block`) имеют наивысший приоритет.
2. **Переопределение по агенту**: индивидуальные настройки агента (`instance_settings.general.guardrailModes.agents[agentId][rule]`).
3. **Переопределение по касте**: настройки касты/роли агента (`instance_settings.general.guardrailModes.castes[caste][rule]`).
4. **Настройки компании**: общее правило на уровне компании (`instance_settings.general.guardrailModes.company[rule]`).
5. **Значение по умолчанию**: `flag` для всех категорий, если переопределений нет.

API разрешения (`GET /api/myrmidon/companies/:companyId/guardrails/effective`) возвращает эффективный режим вместе с источником (`env`, `agent`, `caste`, `company` или `default`).

## Сохранение настроек и горячее чтение

Режимы ограждений сохраняются в `instance_settings.general.guardrailModes` через авторизованные маршруты:
- `GET /api/myrmidon/companies/:companyId/guardrails/settings`
- `PUT /api/myrmidon/companies/:companyId/guardrails/settings`

Изменения вступают в силу немедленно для последующих ответов агентов и очередей без перезапуска сервера. Другие настройки компании (лимиты WIP, поведенческие настройки) сохраняются без потерь.

## Безопасные границы и журнал

- **Граница сканирования**: Анализируются не более первых 262 144 символов текста.
- **Ограничение на события**: Не более 20 событий за один прогон.
- **Фрагменты**: Сохраняемые сниппеты обрезаются до 200 символов и маскируются по форме.
- **Журнал событий и UI**: Журнал (`GET /api/myrmidon/companies/:companyId/guardrails/journal`) поддерживает фильтры по `kind`, `severity`, `surface` и `runId`. Экран UI включает двуязычную локализацию (EN/RU).
