# Фуражировка: сбор знаний из одобренных источников (1.6 FORAGING)

Foraging позволяет колонии собирать свежие знания из одобренных внешних
источников и превращать изменения в кандидатов в навыки. Оператор регистрирует
источники по ролям; периодический проход перечитывает каждый включённый
источник, сравнивает его со сохранённым снимком и записывает каждое изменение
как находку; находка, принятая жизненным циклом навыков, становится кандидатом
в навык и дальше проходит обычное согласование жизненного цикла, прежде чем её
увидит хоть один агент.

Модуль — `server/src/myrmidon/foraging/` (путь 1.6 FORAGING); экран —
`/foraging`, пункт сайдбара рядом с Quality.

## Выключено по умолчанию

Foraging поставляется ВЫКЛЮЧЕННЫМ. Встроенное умолчание — выкл: без
инстанс-выключателя (`enabled` в секции «Learning (foraging)» на Instance →
General, ключ `general.foraging`) и без принудительного env
`MYRMIDON_FORAGING_ENABLED=1` таймер не взводится и ни один источник не
читается; любое другое значение оставляет фичу выключенной, так что опечатка
её не включит. Выключатель живой — свип перечитывает строку настроек перед
каждым проходом, поэтому включение или выключение обучения в интерфейсе
действует со следующего прохода, без перезапуска (FORAGING-LIMITS-UI, 1.6.4).
Реестр и список находок
остаются читаемыми и редактируемыми, пока проход выключен: экран показывает
пометку, что проходы не идут, а ручной проход отвечает `503` с
`enabled: false`.

## Реестр источников

Каждая компания ведёт свой реестр (таблица `foraging_sources`, миграция
`0290`). Одна строка — один источник на одну роль: `role`, `url`, `kind`
(`url`, `feed`, `repo`, `docs`), `enabled`, плюс последний снимок, метки
времени последнего снимка и последней проверки и последняя ошибка. Один
источник на `(company, role, url)` — повторное сохранение той же пары роль+url
обновляет строку.

## Как устроен проход

Один проход по одной компании:

1. Взять включённые источники, начиная с давно не проверявшихся.
2. Прочитать каждый источник (простой `GET`; ответ ограничен 512 КБ, бо́льший
   ответ обрезается, а не отвергается).
3. Нормализовать текст в одну обрезанную строку на элемент (пустые строки
   отброшены, дубликаты слиты, порядок не важен) и сравнить со сохранённым
   снимком. Первое чтение источника сохраняет базовую линию и не открывает
   находок.
4. Изменение (добавленные или удалённые строки, до 50 строк на сторону)
   становится находкой в `foraging_findings` с однострочной сводкой и
   целевым ключом навыка `foraged-<role>`.
5. Находка становится кандидатом в навык только через порт кандидатов — шов с
   жизненным циклом навыков (SKILL-LIFECYCLE). Пока порт отсутствует, находка
   остаётся `unverified`; когда цикл подключён, принятая находка становится
   `candidate` со ссылкой на кандидата, отвергнутая — `rejected` с причиной.
6. Остановить проход, когда оценка стоимости достигает потолка бюджета
   (`stopped_by_budget`). Остановка — нормальный исход: источники после неё
   остаются нетронутыми, и следующий проход продолжает с них.

Источник, который не ответил, пишет ошибку в свою строку, а проход идёт
дальше; сломанный источник никогда не останавливает свип. Проход, который
пересёкся с предыдущим, пропускается, а не ставится в очередь.

Чтение — единственное место, где фича говорит с внешним миром, и у него свои
правила: пауза между двумя чтениями одного хоста
(`MYRMIDON_FORAGING_MIN_HOST_INTERVAL_SEC`, по умолчанию 60 с), честный
User-Agent (`myrmidon-foraging/1.0`) и размыкатель, который оставляет хост в
покое на 6 часов после двух отказов подряд. Пауза и размыкатель общие для всех
компаний процесса, так что две роли, указывающие на один хост, не могут
удвоить частоту. Когда `MYRMIDON_FORAGING_KEY_SECRET` называет секрет
компании, его значение уходит как bearer-токен; значение читается в момент
вызова и никогда не пишется в логи и не хранится.

## Настройки

С 1.6.4 (FORAGING-LIMITS-UI) рабочие параметры — **настройки инстанса**:
секция «Learning (foraging)» на Instance → General
(`GET`/`PATCH /api/myrmidon/foraging-settings`, ключ `general.foraging`)
держит главный выключатель, интервал прохода, паузу между чтениями одного
хоста, бюджет одного прохода, суточный и месячный потолок компании, суточные
потолки роли и агента, режим исполнения hard/soft и порог автоотключения по
стоимости задачи. Свип перечитывает эту строку перед **каждым** проходом,
поэтому изменённое значение действует со следующего прохода — без перезапуска.

Переменные окружения не исчезают: каждая остаётся **принудительным
переопределением** своего поля (значение UI → env, если задан → встроенное
умолчание), и панель показывает, какая сторона действует для каждого поля:

| Переменная | Переопределяет | Умолчание |
|---|---|---|
| `MYRMIDON_FORAGING_ENABLED` | `enabled` | выкл |
| `MYRMIDON_FORAGING_INTERVAL_SEC` | `intervalSec` | `3600` (60–86400) |
| `MYRMIDON_FORAGING_MIN_HOST_INTERVAL_SEC` | `minHostIntervalSec` | `60` (≥ 5) |
| `MYRMIDON_FORAGING_BUDGET_CENTS` | `passBudgetCents` | `50` |
| `MYRMIDON_FORAGING_DAILY_BUDGET_CENTS` | `dailyBudgetCents` | не задано (без лимита) |
| `MYRMIDON_FORAGING_MONTHLY_BUDGET_CENTS` | `monthlyBudgetCents` | не задано (без лимита) |
| `MYRMIDON_FORAGING_ROLE_BUDGET_CENTS` | `roleBudgetCents` | не задано (без лимита) |
| `MYRMIDON_FORAGING_AGENT_BUDGET_CENTS` | `agentBudgetCents` | не задано (без лимита) |
| `MYRMIDON_FORAGING_ENFORCEMENT` | `enforcement` | `hard` |
| `MYRMIDON_FORAGING_AUTO_OFF_COST_PER_TASK_CENTS` | `autoOffCostPerTaskCents` | не задано (проверка выключена) |

`MYRMIDON_FORAGING_KEY_SECRET` остаётся только env: это **имя** секрета
компании, а не лимит, поэтому в строке настроек ему не место. Пустое поле
центов — лимита этого вида нет. Полная таблица с границами — в
[../SETTINGS.ru.md](../SETTINGS.ru.md).

Когда лимит останавливает проход (источники после остановки не трогаются), в
«Ждёт меня» падает карточка `foraging_limit`; мягкий режим помечает её как
вопрос владельцу (поднять лимит или выключить обучение). Когда средняя
стоимость задачи (BASELINE) поднимается выше порога автоотключения, обучение
выключает само себя и сигналит в ту же ленту.

## Экран

Пункт сайдбара «Foraging» (маршрут `/foraging`) показывает три вещи:

- **реестр источников** с формой добавления (роль, url, kind), состоянием
  каждой строки (последний снимок, последняя проверка, последняя ошибка) и
  кнопкой удаления;
- **находки** — каждая с диффом (`+N −M`), сводкой, целевым ключом навыка,
  состоянием (`unverified` / `candidate` / `rejected`) и ссылкой на кандидата
  или причиной отказа;
- **строку бюджета** — бюджет прохода (или «без лимита»), оценку расхода за
  текущий месяц UTC, период прохода и паузу для одного хоста — плюс кнопку
  «Run sweep», запускающую один проход вручную (недоступна, пока фича
  выключена).

Экран работает и при выключенном проходе: реестр остаётся редактируемым, а
находки — читаемыми, с пометкой, что проходы не идут.

## API

Все маршруты живут под `/api/myrmidon/companies/:companyId/foraging`:

| Маршрут | Кто | Что делает |
|---|---|---|
| `GET /sources` | чтение компании | Реестр плюс признак, включён ли проход |
| `PUT /sources` | только доска | Добавляет или обновляет источник (`role`, `url`, `kind`, `enabled`) |
| `DELETE /sources/:sourceId` | только доска | Удаляет источник |
| `GET /findings?limit` | чтение компании | Находки, новые первыми (`limit` по умолчанию 50, максимум 200) |
| `GET /budget` | чтение компании | Представление бюджета для экрана |
| `GET /spend` | чтение компании | Разбор расхода обучения (по ролям и источникам, последние 90 дней) — строка «Training» на экране Расходов (FORAGING-LIMITS-UI) |
| `POST /sweep` | только доска | Запускает один проход вручную; отвечает `503 {enabled: false}`, пока проход выключен |

Сами лимиты живут вне компанийских маршрутов:
`GET`/`PATCH /api/myrmidon/foraging-settings` (настройки инстанса, доступ
органа доски / админ инстанса) читают и пишут `general.foraging`.

Чтения требуют доступа к компании; мутации — актора доски: ручной проход
тратит настоящие внешние чтения. Каждая мутация пишет строку в журнал
активности (`myrmidon.foraging.source_saved`,
`myrmidon.foraging.source_removed`, `myrmidon.foraging.sweep_run`).

## От находки до агента

Ничто из сказанного источником не доходит до агента напрямую. Находка с
диффом уходит в жизненный цикл навыков через порт кандидатов; принятый
кандидат дальше следует правилам цикла (`candidate` достаётся только
пилотным агентам из `MYRMIDON_SKILL_PILOT_AGENTS`, промоушен — через
согласование) и проходит ревью на экране жизненного цикла навыков
(`/skills/lifecycle`), прежде чем дойти до всех.
