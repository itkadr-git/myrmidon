# Бюджеты LiteLLM-ключей

> English version: [litellm-key-budgets.md](litellm-key-budgets.md)

Вкладка Gateway Keys показывает бюджеты ключей агентов и служб, спроецированные из существующей проекции бюджетов OPE-8675. Второе хранилище бюджетов не создаётся, а исходные значения gateway-ключей никогда не возвращаются.

## API

`GET /api/myrmidon/companies/:companyId/litellm/key-budgets`

Ответ содержит:

- `agents`: безопасные метаданные ключей агентов и лимит их caste;
- `services`: безопасные метаданные служб/областей и проецированные лимиты;
- состояния `signalOnly` и `projectionEnabled`.

Данные читаются из `instance_settings.general.myrmidonBudgetProjectionCompanies[companyId]` — того же документа, который использует API настроек проекции бюджетов. Секретные значения не включаются: в представлении ключей допустимы только имена секретов, признак наличия и хеш значения.

## Поведение UI

Вкладка Gateway Keys отдельно запрашивает `key-budgets` и метаданные ключей. Она показывает для агентов и служб сумму, период и эффективный режим `soft`/`block`. Если запрос бюджетов завершается ошибкой, UI показывает ошибку, сохраняя карточку ключей. Отсутствующая или пустая проекция показывается как пустое состояние.

Обновление выполняется через существующую точку изменения OPE-8675 (`mutateBudgetProjectionDocument`). Эта атомарная операция read-modify-write не оставляет частично сохранённый документ при ошибке валидации или базы данных.
