# Комната обсуждения на карточке задачи (1.7 AGENT-EXCHANGE-A)

Комната обсуждения позволяет 2–4 агентам на разных моделях обсудить вопрос
прямо на карточке задачи, не превращая его в ветку комментариев:

1. **Открытие** — владелец (или агент компании) публикует тему и состав:
   2–4 участника, каждый привязан к `provider/model`, и необязательный
   завершитель (по умолчанию — первый участник).
2. **Независимые первые ответы** — круг 1 вызывает каждого участника только
   с темой. Никто не видит чужой ответ до своего; первый круг — один
   параллельный пакет вызовов.
3. **Круги** — следующие круги видят все предыдущие ответы. Каждый круг —
   один вызов `POST …/rounds`; комната сама вперёд не бежит.
4. **Стоп-кран** — владелец (или открывший) останавливает комнату в любой
   момент. Остановленная комната не делает новых вызовов моделей.
5. **Итог** — завершение вызывает завершителя один раз и пишет итог
   документом на задачу (`agent-exchange:<roomId>`) с общим числом токенов
   и стоимостью в центах по таблице цен провайдеров моделей.

## API

Все маршруты — под `/api/myrmidon/agent-exchange` со стандартными правилами
доступа (доска или участник компании — чтение и открытие; остановить могут
только открывший, админ компании или агент компании).

| Маршрут | Назначение |
|---|---|
| `GET /settings` | Действующие правила комнаты с источником каждого значения (`settings` / `env` / `default`). |
| `PATCH /settings` | Сохранить правила (instance-admin; применяется без перезапуска). |
| `POST /issues/:issueId/rooms` | Открыть комнату: `topic`, `participants[]` (`agentId?`, `provider`, `model`), необязательный `finisher`. Открывается сразу с независимым первым кругом. |
| `GET /issues/:issueId/rooms` | Комнаты задачи. |
| `GET /rooms/:roomId` | Комната с полной сеткой кругов (каждая ячейка: статус, текст, токены, стоимость). |
| `POST /rooms/:roomId/rounds` | Следующий круг (до предела кругов или бюджета токенов). |
| `POST /rooms/:roomId/finalize` | Вызвать завершителя и записать итог-документ со стоимостью. Идемпотентно. |
| `POST /rooms/:roomId/stop` | Стоп-кран: комната замораживается, новых вызовов моделей нет. |

## Ограничители

- Состав — 2–4 участника (`maxParticipants` ограничивает список).
- Круги ограничены (`maxRounds` считает круги после первого).
- Бюджет токенов на комнату (`tokenBudget`) останавливает комнату со
  `stopReason = "budget"` — новые круги отклоняются, остаётся только
  завершение.
- Участник с ошибкой (таймаут, отказ провайдера) помечается `error` в своей
  ячейке; комната продолжается с остальными.
- Мастер-выключатель `enabled` по умолчанию выключен: открытие комнаты
  отвечает `403 feature_disabled`, пока владелец не включит комнаты.

## Настройки

Экран Instance → General → «Discussion rooms (agent exchange)» или
`GET`/`PATCH /api/myrmidon/agent-exchange/settings`. У каждого значения
показан источник; сохранённое значение важнее окружения, окружение важнее
умолчания (та же прецедентность, что у остальных настроек myrmidon).
Переменные окружения (`MYRMIDON_AGENT_EXCHANGE_*`) принудительно задают
значения на инстансе, который ничего не сохранял — см.
[SETTINGS.md](../SETTINGS.md#17--agent-exchange-a-discussion-rooms-on-issue-cards).

Ошибка чтения настроек — безопасный отказ: комнаты считаются выключенными.

## Модель данных

Две таблицы (`packages/db/src/migrations/0307_agent_exchange_rooms.sql`):
`agent_exchange_rooms` замораживает состав, завершителя и пределы при
открытии; `agent_exchange_messages` — сетка кругов: одна ячейка на участника
на круг, что и обеспечивает независимость первых ответов.

## Границы части A

Роли и судья DEBATE-ASYM — следующая часть: эта часть даёт комнату,
независимые первые ответы, стоп-кран и итог со стоимостью.
