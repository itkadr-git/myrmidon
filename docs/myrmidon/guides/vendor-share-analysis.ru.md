# Инструмент анализа доли вендорного кода

## Обзор
Этот скрипт анализирует долю файлов, происходящих от вендорного кода, в репозитории Myrmidon по сравнению с оригинальной базой Paperclip.

## Использование
```bash
# Запуск анализа с порогом 50% по умолчанию и вывод краткого отчета в формате markdown
node scripts/myrmidon/vendor-share.mjs

# Запуск с пользовательским порогом (например, 70%)
node scripts/myrmidon/vendor-share.mjs --threshold 0.7

# Вывод результатов в формате JSON
node scripts/myrmidon/vendor-share.mjs --json

# Показать справку
node scripts/myrmidon/vendor-share.mjs --help
```

## Конфигурация
- Скрипт читает базовый вендорный коммит из файла `scripts/myrmidon/vendor-base.txt`
- Порог схожести по умолчанию составляет 50% (0.5)
- Файлы, соответствующие шаблонам исключения, игнорируются (файлы блокировок, артефакты сборки и т.д.)

## Вывод
Скрипт предоставляет:
- Общее количество файлов в репозитории
- Количество и процент вендорных файлов
- Разбивку по каталогам верхнего уровня
- С `--json`: каждый вендорный файл с коэффициентом схожести

## Логика
Файл считается вендорным, если:
1. Он существовал в базовом вендорном коммите
2. Коэффициент схожести (на основе общих строк) выше порогового значения
3. Он не входит в список исключений

Схожесть вычисляется путем сравнения нормализованного содержимого (нормализованные окончания строк, убраны пробелы, нет пустых строк) и вычисления отношения общих строк к максимальной длине двух файлов.
