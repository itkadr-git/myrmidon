# Ключи плагинов (Plugin Entitlement Keys)

Ключи плагинов позволяют администраторам контролировать, какие плагины включены в экземпляре. Эта функция позволяет реализовать модель лицензирования, при которой определенные премиум-плагины требуют действующий ключ для активации.

## Обзор

Система ключей плагинов позволяет:
- Добавлять лицензионные ключи для плагинов, которым они требуются
- Просматривать статус каждого плагина (включен, требует ключ, ключ истек)
- Управлять ключами плагинов со страницы настроек экземпляра

## Добавление ключа плагина

1. Перейдите в Настройки экземпляра → Ключи плагинов
2. Введите лицензионный ключ плагина в поле ввода
3. Нажмите "Добавить ключ"

Система автоматически свяжет ключ с соответствующим плагином на основе формата ключа.

## Формат ключа

Ключи плагинов следуют формату: `PC-{ID_ПЛАГИНА}-{ДАТА_ИСТЕЧЕНИЯ}-{КОНТРОЛЬНАЯ_СУММА}`
- `PC-`: Префикс, указывающий, что это ключ Paperclip
- `{ID_ПЛАГИНА}`: ID плагина, для которого предназначен ключ
- `{ДАТА_ИСТЕЧЕНИЯ}`: Необязательная дата истечения в формате ГГГГММДД
- `{КОНТРОЛЬНАЯ_СУММА}`: Контрольная сумма для проверки

Пример: `PC-enterprise-features-20251231-A1B2C3D4E5F`

## Интеграция с манифестом плагина

Плагины, которым требуются ключи, должны включать поле `requiresEntitlement: true` в своем манифесте:

```json
{
  "id": "paperclip.enterprise-features",
  "requiresEntitlement": true,
  // ... другие поля манифеста
}
```

## Индикаторы статуса

- **Действителен**: Плагин включен и ключ действителен
- **Истек**: Плагин отключен, потому что срок действия ключа истек
- **Недействителен**: Плагин отключен, потому что ключ недействителен или имеет неправильный формат
