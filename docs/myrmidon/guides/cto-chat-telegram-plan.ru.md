# CTO-CHAT: Команда /plan в Telegram

> Английская версия: [cto-chat-telegram-plan.md](cto-chat-telegram-plan.md)

## Описание
Команда `/plan` позволяет владельцу компании создавать эпик-планы из личного сообщения в Telegram. При отправке команды `/plan <описание задачи>` система создает карточку планирования на доске и возвращает ссылку на нее.

## Функциональность
- Команда доступна только владельцу компании (пользователь с ролью `owner`)
- При успешном выполнении создает карточку типа `suggest_tasks` на задаче-разговоре
- Ответ содержит ссылку на созданную карточку планирования
- В случае ошибки возвращается понятное сообщение без трассировки стека

## Использование
```
/plan создать новую функциональность для авторизации пользователей
```

## Требования
- Пользователь должен иметь роль `owner` в компании
- CTO-CHAT должен быть настроен на сервере (должны быть указаны `MYRMIDON_CTO_CHAT_BASE_URL` и `MYRMIDON_CTO_CHAT_KEY_SECRET` — см. `docs/myrmidon/SETTINGS.md`, раздел 1.6-CTO-CHAT-B)
- Компания должна иметь настроенный API-ключ в секретах

## Настройка на лету
Контур планировщика (адрес, имя ключевого секрета, модель) читается при каждом вызове: смена адреса, ротация имени секрета или модели подействует на следующую команду `/plan` без перезапуска сервера. Отдельного переключателя у команды нет: при незаданном CTO-CHAT она отвечает «I cannot plan right now» — тем же ответом, что экран портала.

## Безопасность
- Команда проверяет, является ли отправитель владельцем компании
- Конфиденциальные данные не раскрываются в сообщениях об ошибках
- Доступ к API-ключу осуществляется через безопасное хранилище секретов
