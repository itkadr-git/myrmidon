# Имена переменных окружения: MYRMIDON_* с алиасом PAPERCLIP_*

> English version: [env-names-alias.md](env-names-alias.md)

С выпуска 1.7 все переменные окружения продукта читаются под именем
`MYRMIDON_<ОБЛАСТЬ>_<ИМЯ>`. Прежние написания `PAPERCLIP_<ОБЛАСТЬ>_<ИМЯ>`
работают ещё один релиз как алиасы, чтобы установленная система или навык
агента, экспортирующий старые имена, не сломался.

## Как работает алиас

- Продукт сначала читает `MYRMIDON_*`. Если заданы оба имени —
  `MYRMIDON_<ИМЯ>` и `PAPERCLIP_<ИМЯ>` — побеждает новое.
- Если задано только `PAPERCLIP_<ИМЯ>`, значение используется, а в журнал
  пишется одно предупреждение об устаревании на имя переменной, например:

```
myrmidon: environment variable PAPERCLIP_LOG_LEVEL is a deprecated alias of MYRMIDON_LOG_LEVEL; The PAPERCLIP_* variable names are deprecated aliases for MYRMIDON_*; they will stop working in a future release. Rename them in your environment.
```

- Предупреждение выдаётся один раз на имя переменной за процесс, а не на каждое
  чтение.
- Пустое значение считается незаданным для обоих имён (конвенция dotenv).

Внутренние переменные, которые продукт пишет сам (идентификация прогона,
указатели воркспейса, доступ к API для дочерних процессов), в окно алиаса
выставляются под обоими написаниями, чтобы дочерние процессы, ожидающие
`PAPERCLIP_*`, продолжали работать. Санитайзеры, вырезающие продуктовые
переменные из окружения дочерних процессов, вырезают оба написания.

## Где лежит таблица соответствия

Полная таблица соответствия имён — в
[SETTINGS.md](../SETTINGS.md), раздел
«Name mapping PAPERCLIP_* → MYRMIDON_*». Там перечислена каждая переменная,
которую читает продукт.

## Миграция установки

1. Переименуйте переменные в окружении (файлы `.env`, юниты systemd,
   описания контейнеров): `PAPERCLIP_X=Y` становится `MYRMIDON_X=Y`.
2. Перезапустите сервер. Больше ничего не меняется: значения, умолчания и
   приоритеты внутри переменной те же.
3. Следите за журналом: предупреждения об устаревании называют каждую
   переменную, ещё заданную старым именем.
4. Уберите старые имена до релиза, следующего за 1.7: окно алиаса — один
   релиз по решению владельца.
