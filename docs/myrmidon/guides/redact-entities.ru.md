# Распознавание сущностей REDACT

Маршрут `POST /api/myrmidon/guardrails/entities` возвращает позиции и оценку уверенности для каждого совпадения. Распознавание детерминированное, без LLM. Оценка эвристическая, не вероятность; порог выбирает потребитель, нельзя блокировать только из-за наличия совпадения.

ИНН, СНИЛС, карты и регистрационные номера проверяются по контрольным разрядам. Если на строке со счётом указан ровно один БИК с меткой, счёт проверяется по нему, а несовпадающий счёт не возвращается. Без единственного БИК на той же строке счёт возвращается с меньшей уверенностью без такой проверки. Эта эвристика не определяет принадлежность счёта банку в произвольном документе. Интерфейс словаря предусмотрен для интеграции; данный маршрут словарь не подключает.
