# Система управления ключами плагинов (Plugin Entitlement System)

## Обзор

Система управления ключами плагинов предоставляет механизм контроля доступа к плагинам через криптографические ключи активации. Эта система позволяет авторам плагинов требовать действительный ключ активации перед тем, как плагин может быть активирован и использован в экземпляре Myrmidon.

## Архитектура

### Компоненты

1. **Ключи активации**: Криптографически подписанные токены с использованием подписей Ed25519
2. **Хранилище базы данных**: Ключи активации хранятся в таблице `plugin_entitlements`
3. **Сервис проверки**: Сервис `isEntitled()` проверяет права доступа к плагинам
4. **Маршруты API**: Конечные точки REST для управления ключами активации
5. **Интеграция манифеста плагина**: Плагины могут указывать `requiresEntitlement` в своем манифесте

### Структура данных

Ключ активации содержит:
- ID плагина
- ID экземпляра
- Метку времени истечения
- Подпись (Ed25519)

## Детали реализации

### Формат ключа активации

Ключи активации следуют формату: `base64(payload).base64(signature)`

Полезная нагрузка содержит:
```json
{
  "pluginId": "идентификатор-плагина",
  "instanceId": "id-экземпляра-myrmidon",
  "expiresAt": "2024-12-31T23:59:59.000Z",
  "issuedAt": "2024-01-01T00:00:00.000Z"
}
```

### Схема базы данных

Таблица `plugin_entitlements` включает:
- `id`: Уникальный идентификатор активации
- `plugin_id`: Ссылка на плагин
- `entitlement_key`: Хешированное хранение ключа активации
- `public_key`: Открытый ключ для проверки подписи
- `instance_id`: Экземпляр, для которого действителен ключ
- `expires_at`: Метка времени истечения
- `created_at`: Метка времени создания
- `updated_at`: Метка времени последнего обновления

### Особенности безопасности

1. **Криптографическая проверка**: Использует подписи Ed25519 для безопасной проверки
2. **Проверка истечения**: Автоматическая проверка периода действия активации
3. **Привязка к экземпляру**: Активации привязаны к конкретным экземплярам
4. **Безопасное хранение**: Исходные ключи активации не хранятся; только хеши или частичные ключи
5. **Контроль доступа администратора**: Только администраторы экземпляра могут управлять активациями

## Использование

### Для авторов плагинов

Чтобы потребовать ключ активации для вашего плагина, добавьте свойство `requiresEntitlement` в манифест плагина:

```typescript
export const manifest: PluginManifest = {
  id: 'премиум-плагин',
  name: 'Премиум плагин',
  description: 'Плагин, требующий ключ активации',
  version: '1.0.0',
  requiresEntitlement: true, // Этот флаг указывает, что плагин требует ключ активации
  // ... другие свойства манифеста
};
```

### Для администраторов

#### Добавление активации

Используйте конечную точку API для добавления новой активации:

```
POST /api/plugin-entitlements
```

Тело запроса:
```json
{
  "pluginId": "идентификатор-плагина",
  "entitlementKey": "ключ-активации.здесь",
  "publicKey": "публичный-ключ-для-проверки",
  "instanceId": "ваш-id-экземпляра",
  "expiresAt": "2024-12-31T23:59:59.000Z"
}
```

#### Проверка статуса активации плагина

Проверьте, имеет ли плагин активацию:

```
GET /api/plugin-entitlements/:pluginId
```

#### Список всех активаций

Получите все активации для текущего экземпляра:

```
GET /api/plugin-entitlements
```

#### Удаление активации

Удалите активацию по ID:

```
DELETE /api/plugin-entitlements/:id
```

## Методы сервиса

### `isEntitled(pluginKey)`

Проверяет, разрешено ли использование плагина в текущем экземпляре. Результаты кэшируются на 5 минут.

### `verifyEntitlementSignature(entitlementKey, publicKey)`

Проверяет криптографическую подпись ключа активации.

### `generateEntitlementKey(pluginId, instanceId, expiresAt)`

Генерирует новый ключ активации (в основном для целей тестирования).

### `clearEntitlementCache()`

Очищает кэш активаций, заставляя выполнить новые проверки при следующем доступе.

## Тестирование

Комплексные тесты включены в файлы `*.myrmidon.test.ts` для проверки:

- Обнаружения недействительной подписи
- Отклонения истекших активаций
- Обнаружения поддельных ключей
- Поведения кэширования
- Функциональности конечных точек API
