# Экран «Серверы» в UI2 (/fleet)

> English version: [ui2-servers.md](ui2-servers.md)

Экран «Серверы» (`/fleet`) показывает живое состояние узлов, служб и удалённых
площадок, на которых работает развёртывание. Данные берутся из API панели
мониторинга (`/api/myrmidon/monitoring/dashboard`); подключение источников
описано в [fleet-dashboard-monitoring.ru.md](fleet-dashboard-monitoring.ru.md).

## Что показывает экран

- **Площадки** (если настроены): состояние каждой удалённой площадки и когда её видели в последний раз.
- **Узлы**: нагрузка CPU, памяти и диска по каждому узлу.
- **Сервисы**: состояние контейнеров, работает или остановлен.

## Ошибки мониторинга

Если мониторинг не настроен или недоступен, экран сообщает об этом над списками
вместо «Ресурсов флота пока нет». Сообщение появляется, когда панель отвечает
`ok=false` или любой источник вернул `error`. Текст ошибки каждого источника
выводится под сообщением; если текста нет ни у одного, показывается «Данные
мониторинга недоступны.» Пустое состояние видно только при исправном мониторинге
и действительно пустых данных.

Пока компания не выбрана, экран остаётся в состоянии загрузки.

## В меню

В меню два пункта: «Агенты» (`/agents`) и «Серверы» (`/fleet`). В мобильной
панели вкладок на `/agents` подсвечивается только «Агенты», без «Ещё».
