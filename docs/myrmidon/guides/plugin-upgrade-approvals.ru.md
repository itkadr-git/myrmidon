# Одобрение возможностей при обновлении плагина

Администратор экземпляра должен одобрить каждую возможность, которую добавляет обновление плагина.

## Порядок через API

1. Отправьте `POST /api/plugins/:pluginId/upgrade` без поля `approvedCapabilities`.
2. Если новый пакет добавляет возможности, сервер вернёт `400` и точный список возможностей.
3. Проверьте список и повторите запрос с теми же именами:

```json
{
  "approvedCapabilities": ["access.members.read"]
}
```

Список должен содержать каждую добавленную возможность ровно один раз. Отсутствующие, лишние и повторяющиеся имена отклоняются. Обновление без новых возможностей одобрения не требует.

Сервер записывает в журнал действий одобрившего пользователя, время и список возможностей. Настройки установленного плагина при обновлении не удаляются.

На странице «Плагины» первый запрос выполняется автоматически. После отказа отображаются запрошенные возможности и кнопка «Approve and upgrade» для администратора экземпляра.
