# Сухой прогон переадресации интеракций

Перед любым изменением адресатов сформируйте отчёт для целевой базы данных:

```sh
DATABASE_URL="$DATABASE_URL" pnpm exec tsx scripts/myrmidon/interactions/readdress-report.ts --format=json
DATABASE_URL="$DATABASE_URL" pnpm exec tsx scripts/myrmidon/interactions/readdress-report.ts --format=csv
```

Скрипт открывает транзакцию PostgreSQL в режиме только чтения (`read-only`) и не модифицирует строки интеракций. Переменная `DATABASE_URL` должна указывать на нужное окружение. Параметр `--format` принимает значения `json` (по умолчанию) или `csv`. Используйте `--format=csv`, если данные удобнее анализировать в табличном редакторе.

Коды завершения:
- `0` — отчёт успешно записан в стандартный вывод (`stdout`).
- `1` — ошибка базы данных или выполнения запроса.
- `2` — отсутствует `DATABASE_URL` или передан некорректный формат.

Команда и поля отчёта не зависят от языка интерфейса.
