# Исправление проблемы WAKE-STALL-ROOT B

## Описание проблемы
После смены исполнителя задачи (`PATCH /api/issues/{id}` с новым `assigneeAgentId`) отложенное выполнение задачи (`deferred_issue_execution`) переходит к новому исполнителю и будит его, вместо того чтобы застрять у старого исполнителя.

## Коренная причина
Когда задача переопределяется от одного агента другому, система не отменяла надлежащим образом отложенные выполнения, связанные со старым исполнителем. Это приводило к:
1. Старый агент сохранял устаревшие отложенные выполнения
2. Новый исполнитель не получал надлежащих пробуждений
3. Проблемы с обработкой переопределенной задачи

## Реализованное решение

### 1. Новый метод сервиса
Добавлен новый метод `cancelDeferredExecutionsForAgentOnReassignment` в сервис задач для отмены всех отложенных выполнений для старого исполнителя при переопределении задачи.

### 2. Интеграция в обработчик PATCH
Модифицирован обработчик PATCH в `server/src/routes/issues.ts` для вызова метода отмены при изменении исполнителя.

### 3. Надлежащая обработка крайних случаев
- Обработка случаев, когда нет отложенных выполнений для старого исполнителя
- Обеспечение отмены только выполнений, связанных с конкретной задачей
- Поддержание надлежащего журналирования событий отмены
- Учет состояния паузы агентов - приостановленные агенты остаются в состоянии паузы, но их отложенные выполнения очищаются

## Измененные файлы

### server/src/services/issues.ts
- Добавлен метод `cancelDeferredExecutionsForAgentOnReassignment` для отмены отложенных выполнений для старого исполнителя
- Метод корректно фильтрует по ID задачи и ID агента, чтобы избежать отмены несвязанных выполнений

### server/src/routes/issues.ts
- Улучшена логика детекции изменения исполнителя
- Добавлен вызов метода отмены при изменении исполнителя

### Тестовое покрытие
- Добавлены комплексные тесты в `server/src/services/issues.reassignment.test.ts`
- Тесты охватывают обычные сценарии переопределения
- Тесты охватывают крайние случаи (нет отложенных выполнений, несколько отложенных выполнений)
