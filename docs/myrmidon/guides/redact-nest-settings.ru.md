# REDACT: настройка по гнезду

Настройка REDACT хранится по `nest_id` в `instance_settings.general.nestRedactByNest`. Она перечитывается при каждом запросе: изменение одного гнезда не влияет на другие и не требует перезапуска.

Администратор экземпляра управляет настройкой через `PATCH /api/myrmidon/nests/:nestId/redact`. В запросе можно задать режим, включить правила `counterparties`, `signers`, `contracts`, `invoices`, а также списки номеров договоров и счетов. Словари контрагентов и подписантов задают исходную строку и замену.

`redactNestText(db, nestId, text)` получает конфигурацию выбранного гнезда и применяет только его включённые правила. Для неизвестного гнезда используется безопасная конфигурация по умолчанию.
