# Брендинг продукта в интерфейсе (B1a)

У видимого имени продукта один источник истины: `PRODUCT_NAME` в
`packages/shared/src/myrmidon-product.ts`, экспортируемая через
`@myrmidon/shared`. Компоненты интерфейса импортируют этот символ, а не
создают вторую константу. Заголовок страницы, About и версия в меню учётной
записи используют локализованные ресурсы.

В строках `about.title` и `sidebar.version` на RU и EN сохраняется имя из общей
константы. Проверки в `ui/src/context/BreadcrumbContext.test.tsx` и
`ui/src/components/SidebarAccountMenu.test.tsx` фиксируют имя во вкладке, в
About и в тексте/aria-label версии меню для обеих локалей.

Тест-сторож `ui/src/lib/myrmidon-branding-guard.myrmidon.test.ts` проверяет
видимый текст интерфейса на брендинг вендора, а также заголовок страницы,
манифест и файлы иконок. В пользовательских строках интерфейса исключений для
названий продуктов вендора нет. Идентификаторы совместимости (имена пакетов,
HTTP-заголовки, пути API, ключи хранилища) не являются видимым брендингом и
остаются без изменений. Атрибуция MIT в разделе About — намеренное исключение.

Инвентарь изменённых файлов вендора и правило снятия изменений приведены в
[реестре отличий](../DIVERGENCE.md#track-1--platform).

## Перенос ссылок (1.6.6)

Оба варианта меню учётной записи используют общие адреса из
`ui/src/lib/myrmidon-links.ts`. Документация открывает дерево `docs` этого форка
на GitHub. Кнопка обратной связи в не-cloud режиме открывает трекер задач GitHub
этого форка. Правила видимости cloud остаются без изменений.

Кнопка обратной связи по задачам и настройки обратной связи инстанса используют
общий URL условий использования. `VITE_FEEDBACK_TERMS_URL` остаётся переопределением
оператора во время сборки; окружающие пробелы удаляются. Если переменная не задана
или пуста, обе поверхности опускают ссылку на условия. Страница условий апстрима
не является значением по умолчанию для этого форка. Несвязанная страница не
заменяет юридические условия. Операторы, которым нужна эта ссылка, должны указать
применимые условия и пересобрать UI. Хранение голосов, элементы управления согласием
и поведение совместного использования остаются без изменений.

Фоллбэк bootstrap использует команду `myrmidon auth bootstrap-ceo`, соответствующую
исполняемому файлу CLI в нашей поставке. Сторож брендинга покрывает оба варианта
меню учётной записи, оба потребителя условий, общие значения по умолчанию и текст
bootstrap. Тесты ссылок покрывают опущенные условия и переопределения окружения.
Тесты меню учётной записи фиксируют URL обратной связи в обоих вариантах.

ADM проверяет поведение развёрнутого меню и условий после релиза. Это изменение
не меняет конфигурацию production.
