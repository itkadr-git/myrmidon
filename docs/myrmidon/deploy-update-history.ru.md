# Журнал обновлений

> English version: [deploy-update-history.md](deploy-update-history.md)

На странице настроек экземпляра показывается журнал завершённых выкатов из `GET /api/myrmidon/deploy-jobs`. Каждая запись содержит дайджест образа, версию, коммит, режим выката, окно обслуживания, исход и причину сбоя здоровья или отката. При проблеме здоровья запись получает `auto_rolled_back`, если предыдущий образ восстановлен, либо `failed_rollback`, если восстановление тоже не удалось.

В интерфейсе есть независимые фильтры режима (`manual`, `auto`, `canary`), статуса (например `succeeded`, `auto_rolled_back`, `failed_rollback`, `failed_health`, `aborted`) и исхода (`succeeded`, `rollback`, `aborted`). API принимает те же фильтры в query-параметрах: `mode`, `status` и `outcome`.

Текущий job показывается над историей. Записи сохраняются сервисом deploy-jobs, поэтому оператор может посмотреть успешные выкатки и исходы отката после завершения операции.
