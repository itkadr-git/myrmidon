# Env registry 1.6.6 (OPE-8820)

Полный дедуплицированный реестр ИМЁН переменных окружения (значения не собирались). Машинные версии: [`env-registry-1.6.6.json`](env-registry-1.6.6.json), [`env-registry-1.6.6.csv`](env-registry-1.6.6.csv). Полнота проверяется `node scripts/check-env-registry.mjs` (в CI).

## Сверка числа

- Всего уникальных имён в реестре: **883** (secret 109, infra 365, product 409).
- Аудит 08.10 (`settings-without-ui-20261008.md`, раздел C): 665 уникальных = 245 продуктовых (71 с UI, 174 без UI) + 420 инфраструктурных/секретных.
- **«~420» — это не остаток без разбора, а число инфраструктурных и секретных переменных аудита** (таблица 2). Все 665 имён аудита разобраны в реестре.
- Скан main (7a4d9c130) нашёл 741 имён; из них 158 добавлены после аудита 08.10 (или вне его охвата); 82 имён из аудита прямым сканом не найдены (чтение через иную форму либо удалены) — помечены в `consumer`.
- SETTINGS.md упоминает 571 имён (включая таблицу соответствия PAPERCLIP_*).
- Метод и ограничения — в поле `method` и `limitations` JSON. Для имён, добавленных после аудита, `class_basis` = `name-rule`/`settings-md` (правило по имени/пути, не ручной разбор) — подлежит проверке.
