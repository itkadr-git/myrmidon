# Спецификация санкционированного датасета 50 сообщений ADM и версий baseline / current

**Задача**: OPE-9777 (разблокировка OPE-9264)  
**Проект**: 1.6.6 ADM-CONN (OPE-9247 / OPE-9244)  
**Политика безопасности**: OPE-1524 (гигиена секретов, исключение самовольного доступа к журналам сессий)  

---

## 1. Точные версии и коммиты baseline и current

Для проведения офлайн-замера расхода контекста и токенов (контракт A в задаче OPE-9264) без вызова языковых моделей фиксируются следующие исходные параметры схем:

### 1.1. Baseline (эксплуатационная схема ADM до внедрения коннектора)
- **Исполняемая среда**: Claude Code оператора инфраструктуры ADM (`openclaw`) на хосте.
- **Входные артефакты на хосте**:
  - `~/.openclaw/CLAUDE.md`: размер **10,800 байт** (~10.8 KiB). Загружается целиком в контекст при каждом `SessionStart`.
  - `~/.openclaw/MEMORY.md`: размер **13,400 байт** (~13.4 KiB). Загружается целиком в контекст при каждом `SessionStart`.
  - `~/.openclaw/memory/`: 235 файлов памяти (15 активных файлов политик, суммарно **239 KiB**).
- **Поведение хуков в baseline**:
  - `SessionStart`: статическая инъекция `CLAUDE.md` + `MEMORY.md` = **24,200 байт (~24.2 KiB)** контекста на каждую сессию.
  - `UserPromptSubmit`: подгрузка памяти и правил по требованию, в среднем **~800 байт (0.8 KiB)** на каждое сообщение.
- **Фиксация в репозитории**: коммит `590eda445453807b041ce48f8975e5fb90b0e162` (PR #1793 / OPE-9258 — базовая спецификация контракта).

### 1.2. Current (новая схема ADM knowledge connector)
- **Ветви и коммиты реализации**:
  - **PR #1951** (`bot/OPE-9260`, коммит `45fed223f752d48bfdd26ac339d9e59ecbf7496b`): хуки `SessionStart` и `UserPromptSubmit` (`scripts/myrmidon/adm-connector/hooks.mjs`, `cli.mjs`).
  - **PR #1958** (`bot/OPE-9261`, коммит `f3e0528ee1f99fd20ed5a70b67479d336123e501`): верифицированный кэш (`scripts/adm-connector/cache.mjs`).
  - **PR #1959** (`bot/OPE-9262`, коммит `db80305dbf0a9a1027ef9a5ef281b3790ec38cb0`): сафгарды записи и конфликт-менеджмент (`packages/shared/src/adm-knowledge-write.ts`).
  - **PR #1963** (`bot/OPE-9263`, коммит `da227b41df4fc07bfa7cfa6ef0fa95a7b6cf28ec`): скрипт миграции и валидации (`scripts/myrmidon/adm-migrate.mjs`).
- **Бюджетные ограничения current (жесткие инварианты)**:
  - `SessionStart`: в контекст передаются **только** сжатые сводки политик (`title` + `summary` $\le 300$ символов Unicode) и индекс триггеров. Полные тела политик в контекст не грузятся. Жесткий лимит: **$\le 12\text{ KiB}$ ($12{,}288\text{ байт}$)**.
  - `UserPromptSubmit`: детерминированное ключевое сопоставление со словарем триггеров v1 (`ssh`, `deploy`, `paperclip-api`, `incident`, `config-change`, `release`, `merge`, `owner-message`). Жесткий лимит: **$\le 2\text{ KiB}$ ($2{,}048\text{ байт}$)** на сообщение. При отсутствии совпадения триггеров добавляется **ровно 0 байт**.
  - **Дедупликация**: один элемент передается не более одного раза за сессию (дедупликация по `slug + revision_id` в файле сессии). После сжатия контекста повторно передаются только сводки политик.

## 2. UTC-границы недели

Для выборки реальных входящих сообщений ADM зафиксирован временной интервал в ровно 7 суток (168 часов), непосредственно предшествующий старту разработки коннектора:
- **Начало окна (start UTC)**: `2026-10-20T00:00:00Z`
- **Окончание окна (end UTC)**: `2026-10-27T00:00:00Z`

## 3. Воспроизводимое правило выборки и обезличивания

Политика **OPE-1524** категорически запрещает инженерам несанкционированное чтение сырых журналов сессий и утечку секретов. Выборка формируется по детерминированному алгоритму:

1. **Источник сообщений**:
   - Журналы сессий Claude Code оператора ADM на хосте (расположение: `~/.claude/projects/` или `~/.openclaw/`).
2. **Фильтрация входящих сообщений**:
   - Отбираются только сообщения инициатора/пользователя (`role: "user"` или `type: "user"`).
   - Исключаются: системные инъекции, ответы ассистента, результаты выполнения команд и инструментов (`tool_result`), пустые строки и шум.
3. **Обезличивание и удаление секретов (санитизация)**:
   - Прогон через сканер секретов `gitleaks stdin --no-banner --redact=100` (при наличии утилиты).
   - Обязательная регулярная замена чувствительных данных:
     - Ключи доски: `pcp_[A-Za-z0-9_-]+` $\to$ `[REDACTED_PCP_TOKEN]`;
     - Токены GitHub: `gh[pousr]_[A-Za-z0-9_]+` $\to$ `[REDACTED_GH_TOKEN]`;
     - Заголовки авторизации: `Bearer ...` $\to$ `Bearer [REDACTED_BEARER]`;
     - Приватные ключи: `-----BEGIN ... PRIVATE KEY-----` $\to$ `[REDACTED_PRIVATE_KEY]`;
     - Секретные параметры: `(api_key|token|secret|password)=...` $\to$ `[REDACTED_SECRET]`.
4. **Дедупликация и сортировка**:
   - Удаление идентичных сообщений (нормализация по пробелам).
   - Хронологическая сортировка по `timestamp_utc` (при совпадении меток — детерминированная сортировка по тексту).
5. **Равномерная выборка ровно 50 сообщений**:
   - Пусть общее число уникальных сообщений в окне равно $N$.
   - Если $N \ge 50$: рассчитывается равномерный шаг $s = N / 50$, выбираются элементы с индексами $k = \lfloor i \cdot s \rfloor$ для $i = 0, \dots, 49$.
   - Если $N < 50$: берутся все $N$ сообщений и дополняются верифицированными входящими задачами/директивами ADM с доски Myrmidon за тот же период с аналогичной санитизацией.
6. **Выходной формат (`adm-50-messages.json`)**:
   ```json
   [
     {
       "id": 1,
       "timestamp_utc": "2026-10-20T10:15:30.000Z",
       "text": "Текст входящего запроса без секретов",
       "scrubbed": true
     },
     ...
     {
       "id": 50,
       "timestamp_utc": "2026-10-26T22:45:10.000Z",
       "text": "Текст входящего запроса без секретов",
       "scrubbed": true
     }
   ]
   ```

## 4. Скрипт экстрактора

Для автономного запуска оператором ADM на хосте реализован скрипт:
`scripts/myrmidon/adm-connector/extract-adm-dataset.mjs`

### Команда запуска:
```bash
node scripts/myrmidon/adm-connector/extract-adm-dataset.mjs \
  --input-dir ~/.claude/projects \
  --output adm-50-messages.json \
  --start 2026-10-20T00:00:00Z \
  --end 2026-10-27T00:00:00Z \
  --target-count 50
```

Скрипт покрыт автоматическими тестами:
`scripts/myrmidon/adm-connector/extract-adm-dataset.test.mjs` (прогон: `node --test scripts/myrmidon/adm-connector/extract-adm-dataset.test.mjs`).

## 5. Методика офлайн-замера токенов для OPE-9264

В задаче OPE-9264 скрипт замера подает отобранные 50 сообщений на вход хукам baseline и current:
1. **Для baseline**:
   $$\text{Bytes}_{\text{total}} = 50 \times 800\text{ байт} + 24{,}200\text{ байт} = 64{,}200\text{ байт} \approx 62.7\text{ KiB}$$
2. **Для current**:
   $$\text{Bytes}_{\text{total}} = \text{Bytes}(\text{SessionStart}) + \sum_{i=1}^{50} \text{Bytes}(\text{UserPromptSubmit}_i)$$
   где $\text{Bytes}(\text{SessionStart}) \le 12\text{ KiB}$, а для сообщений без совпадения триггеров добавка равна $0$ байт.
3. **Критерий успеха (контракт A)**:
   $$\text{Bytes}_{\text{current}} \le \text{Bytes}_{\text{baseline}}$$
   при нулевом расходе вызовов внешних LLM.
