Myrmidon запускает агентов через серверный контракт адаптера. Сервер выбирает адаптер по конфигурации, передаёт запрос и обработчики отмены, затем сохраняет нормализованный результат, использование, стоимость и состояние продолжения.

## Семейства и gateway

Встроенные адаптеры: `claude_local`, `codex_local`, `process`, `http`; интеграция Hermes добавляет `hermes_local` и `hermes_gateway`. Gateway подключается к уже работающему Hermes API: создаёт удалённый запуск, читает поток событий и переводит финальный статус в контракт Myrmidon. Он не запускает локальный CLI.

При отмене вызывается удалённый endpoint остановки и ожидается подтверждение. Ошибки соединения получают стабильные коды. Незащищённый HTTP запрещён, если явно не разрешён небезопасный транспорт; секреты не включаются в диагностику. Адаптер отвечает за транспорт и тайм-ауты, но не меняет границы компании, approvals или бюджеты.
