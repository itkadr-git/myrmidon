---
title: Agent Chat
summary: Адресация агентов и привязка каналов к разговорам
---

Agent Chat связывает сообщения каналов с разговорами агента и ветками задач. Адресация разрешает упоминания по имени, title и alias; identity различает web- и Telegram-разговоры одного пользователя. Bridge проверяет привязку Telegram DM, создаёт или повторно использует разговор и обрабатывает команды.

Cross-channel helper может добавить ограниченную выдержку из соседнего разговора того же человека как контекст. Она рассматривается как данные, а не инструкции. Код bridge не устанавливает общую гарантию дедупликации webhook-событий по event id или строгого порядка доставки.
