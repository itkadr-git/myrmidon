# ADR-0047: 1.1.0 без стенда, сразу на бой

- Status: accepted
- Date: 2026-09-29
- Deciders: Alex
- Scope: product decision from OPE-401

## Source

- Registry: OPE-401 (`decisions/2026-09-29-1-1-0-no-staging`)

## Decision

Этот релиз на стенде тестировать не будем. Сразу выкатываем на бой. Потом создадим отдельный стенд на отдельной машине для тестов.

## Consequences

Отменяет пункт «проверка на стенде с Docker» из записи «1.1.0 одним выпуском».
