# ADR-0014: Деньги — только через владельца

- Status: accepted
- Date: 2026-09-28
- Deciders: Alex
- Scope: product decision from OPE-401

## Source

- Registry: OPE-401 (`decisions/2026-09-28-money-only-owner`)

## Decision

если не ответил, то да, идёт по рекомендации. Деньги только через меня

## Consequences

Нет ответа к сроку — выпуск идёт по рекомендации. Цены, скидки, акции, рекламный бюджет и любые траты — только после явного «да» владельца.
