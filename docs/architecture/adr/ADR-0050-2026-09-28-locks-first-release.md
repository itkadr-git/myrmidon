# ADR-0050: Убрать замки в первом же новом выпуске вместе со шлюзом hermes

- Status: accepted
- Date: 2026-09-28
- Deciders: Alex
- Scope: product decision from OPE-401

## Source

- Registry: OPE-401 (`decisions/2026-09-28-locks-first-release`)

## Decision

убирание замков нужно в первом же новом релизе вместе с hermes шлюзом

## Consequences

Выпуск 1.1.0 = контейнеры ботов со шлюзом hermes (вариант Б) + разбор замков и удержаний. Типовые обрывы (выкат, рестарт, OOM, успешный прогон без статуса) должны разрешаться по правилу, без красных карточек у владельца.
