# ADR-0010: Myrmidon: своя ветка, без постоянной миграции

- Status: accepted
- Date: 2026-09-28
- Deciders: Alex
- Scope: product decision from OPE-401

## Source

- Registry: OPE-401 (`decisions/2026-09-28-own-branch`)

## Decision

Сузить запрещаю, возможно мы просто будем вести свою ветку и собственную разработку, а на его продукт только посматривать без постоянной миграции

## Consequences

Форк развиваем как свой продукт. Еженедельный автоматический перенос релизов вендора отменяется; вместо него — обзор релизов вендора и выборочный перенос нужного по решению.
