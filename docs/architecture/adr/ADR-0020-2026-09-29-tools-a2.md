# ADR-0020: Инструменты доски для контейнеров: этап А2 вместо Б

- Status: accepted
- Date: 2026-09-29
- Deciders: Alex
- Scope: product decision from OPE-401

## Source

- Registry: OPE-401 (`decisions/2026-09-29-tools-a2`)

## Decision

делаем А2, Б только если понадобится

## Consequences

А2 (выпуск после 1.1.1): вызов инструмента через шлюз бота доска сама привязывает к текущему прогону агента — задача, проект, ответственный, GitHub от лица прогона. Только сервер, hermes не трогаем. Отменяет запись «сначала А, потом Б» в части второго этапа.
