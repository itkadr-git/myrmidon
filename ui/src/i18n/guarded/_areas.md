# План волны выноса надписей (OPE-8950)

Сгенерировано усиленным guard (`guard-scan.ts`) по всем `.tsx` в `ui/src`, кроме тестов и stories: JSX-текст (в том числе многострочный), литералы в `{"..."}`, атрибуты alt, aria-label и др., title, label, placeholder, tooltip, message, intro, description, emptyMessage. Пути относительно `ui/src`. Число в скобках - надписей, найденных guard. Это оценка снизу: строки в шаблонах, полях объектов, константах и тернарных ветках guard не видит.

Область = имя `<area>` для ключей `area.<area>.*`, файлов `areas/<area>.{en,ru}.json` и `guarded/<area>.txt`. Одну область берёт один PR. Области названы по разделам интерфейса; крупные разделы разбиты на части `-1`, `-2` по 7-12 файлов. Файлы из старого списка SCREENS (IssuesList, IssueColumns, Agents, Inbox, IssueDetail, Foraging) лежат в своих областях: прежнее правило их пропускало, усиленное находит надписи.
